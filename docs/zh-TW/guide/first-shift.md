# 第一更當值

## 出發前

- 在當值表上確認你的當值時間及地點。
- 清楚知道當更的主管是誰。
- 帶備學生證 —— 進入大樓或房間時可能需要。
- 衣著整潔。你是許多用戶接觸 ITSC 的第一個人。

## 抵達時

::: tip 開更檢查清單
1. 在當值紀錄上簽到。
2. 閱讀上一更留下的交接筆記。
3. 檢查服務櫃檯／電腦室有沒有未修復或未處理的問題。
4. 登入當更需要用到的系統。
5. 詢問上一更的同事有沒有未完成的事項。
:::

## 當值期間

- 主動招呼每一位前來的用戶。即使只說一句「請稍等一兩分鐘」，也勝過沉默。
- 記錄你處理過的每一宗個案 —— 詳見[服務櫃檯](/zh-TW/duties/service-counter)。
- 若無法在合理時間內解決問題，應升級處理，不要讓用戶一直等。

## 收更時

::: tip 收更檢查清單
1. 完成或交接所有仍在處理中的事項。
2. 為下一更撰寫交接筆記 —— 未解決的個案要寫得具體。
3. 整理櫃檯／電腦室：椅子、線材，外借器材歸位。
4. 登出所有共用帳戶並鎖上工作站。
5. 在當值紀錄上簽退。
:::

## 無法當值時

盡早通知主管，並依照團隊的調更程序處理。切勿在未通知職員的情況下，私下自行安排
他人代更。

:::
