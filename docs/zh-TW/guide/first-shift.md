# 第一更當值

無論被編排到哪一項職務，流程都是同樣的五個步驟。

## 工作流程

1. **自行預訂更份** —— [helperduty.top](https://helperduty.top)
2. **當值時簽到** —— [ics.ln.edu.hk/helper](https://ics.ln.edu.hk/helper)
3. **執行職務** —— 櫃檯、打印機檢查、電腦室檢查等
4. **提交檢查結果** —— 該項職務對應的 Microsoft Forms 檢查表
5. **簽退** —— [ics.ln.edu.hk/helper](https://ics.ln.edu.hk/helper)

::: warning 步驟由系統強制執行
沒有預訂更份就無法簽到；沒有提交檢查結果就無法簽退。漏做第 1 步或第 4 步，系統
都會攔截。
:::

## 1. 更份預訂系統

**[helperduty.top](https://helperduty.top)**

::: warning 只限校園網絡，或經 LUVPN
更份預訂系統**只能在校園 Wi-Fi 網絡內**使用；身處校外時必須先連接 **LUVPN**。

它是一個**獨立的私人資料庫** —— 並沒有與 LU 主要系統連接，所以密碼是學生編號而
非 LU 密碼。**不要向大學其他部門（例如 OSA）透露這個系統的存在。**
:::

### 預訂規則

| 規則 | 內容 |
| --- | --- |
| **櫃檯更份** | 最短可以 **30 分鐘**為單位預訂 |
| **維護檢查** | 打印機、電腦室、課室及早上檢查必須預訂**整個時段** |
| **每週上限** | 系統會強制執行每週工時上限 —— 見[工時與薪酬](/zh-TW/guide/schedule-and-pay#工作時數) |
| **時間重疊** | 重疊的預訂會被**直接攔截** |

只有 Paul 可以在特定理由下豁免工時上限。

### 請假與換更

1. 在 **WhatsApp 發出詳細的請假訊息** —— 姓名、日期、時間、職務及原因。
2. **找同學接更**。接更是**先到先得**。
3. **自行在預訂系統刪除**你的更份。

完整格式與例子見[工作注意事項](/zh-TW/guide/code-of-conduct#請假)。

## 3–4. 執行職務並提交結果

每項職務都有自己的檢查表。請在[職務](/zh-TW/duties/)下找出對應的一項。

## 5. 簽退

如果你在提交結果之前嘗試簽退，頁面會以紅字顯示尚未完成的工作，例如：

> **Missing the following work reports:**
> \*\*\* Printer Check \*\*\* (expected: 1, actual: 0)

![因未提交報告而無法簽退](/images/signout-blocked.jpg)
*未提交檢查結果就無法簽退*

提交結果之後，頁面會顯示 **Duty Completed**，
**Sign Out (Desktop/AV)** 按鈕便會可用。

![Duty Completed 與可用的簽退按鈕](/images/signout-completed.jpg)
*Duty Completed —— 現在可以簽退*

### 簽退之前

1. **提交該項職務的 Microsoft Form。**
2. **等待副本（CC）寄到你的學生電郵** —— 那封收據就是提交成功的憑證。
3. 然後才按 **Sign Out (Desktop/AV)**。

::: danger 一定要用自己的帳戶提交
每一份表格都必須**用自己的帳戶提交**。以他人名義提交的表格不會解除你的簽退限制，
還會把檢查記錄算到別人頭上。
:::

::: warning 必須準時簽退
2 小時的檢查 30 分鐘就做完了？你可以立即提交表格，但**必須等到時間到才簽退**。
每一次早退或遲退都會被記錄，並計入你的助理表現統計。
:::

## 出錯時怎麼辦

忘記簽到或簽退、重複簽到、簽退時間錯誤，或者超時工作？請填寫
**「Abnormal sign in+out」** Excel 檔案，記錄以下內容：

| 欄位 | 填寫內容 |
| --- | --- |
| Date | 出問題的日期 |
| Problem | 例如 Fail to Sign In／Fail to Sign Out／Sign in twice／Sign out wrong time |
| Name | 你的名字 |
| Responsible Timeslot | 例如 13:30–16:00 |
| Wrong Time | 實際被記錄的時間 |
| Correct Time | 應該的正確時間 |
| Type | User service／Counter／Hostel Clinic／others |
| Status | 由主管在調整後填寫 |

![Abnormal sign in+out 試算表](/images/abnormal-signin-sheet.jpg)
*「Abnormal sign in+out」工作簿，每月一個工作表*

另外，凡是提早、遲到或超時**超過 15 分鐘**，都必須通知主管。
