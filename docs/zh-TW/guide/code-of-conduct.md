# 行為守則

作為學生助理，你是代表 ITSC 執行職務。用戶會把你所說的話視為官方說法，因此準確
與專業非常重要。

## 保密責任

- 你在協助用戶期間所看到的一切 —— 檔案、電郵、成績、個人資料 —— 均屬機密。除
  完成工作所必需外不應查閱，事後亦不得外傳或討論。
- 不得拍攝或截取用戶畫面或資料。
- 此項責任在你離職後仍然持續有效。

## 密碼與帳戶

- 絕不要求用戶告訴你他們的密碼。
- 絕不代用戶輸入密碼。應讓用戶自行輸入，並在期間別過頭。
- 絕不將職員或共用帳戶用於指派職務以外的任何用途。
- 絕不將自己的登入資料交給任何人，包括其他學生助理。

## 職權範圍

只做你受過訓練並獲授權的工作。以下情況一律升級處理：

- 伺服器、網絡或保安設定
- 帳戶開立、刪除或權限變更
- 從故障硬碟救回資料
- 任何用戶動怒或正式投訴的情況
- 任何懷疑的保安事故或違規行為

## 專業操守

- 準時。若會遲到，須通知主管。
- 無論用戶的技術水平如何，都要保持耐心和尊重。
- 不得在服務櫃檯進食；當值時手機應收好不外露。
- 平等對待每一位用戶 —— 學生、教職員、訪客及其他學生助理。

## 呈報問題

遇到以下情況，須立即向全職職員呈報：

- 懷疑的資料外洩、惡意軟件感染或釣魚攻擊
- 器材損壞、遺失或被盜
- 任何令你感到不安全或受到騷擾的用戶行為

只要是出於善意呈報，你絕不會因此被責備。
