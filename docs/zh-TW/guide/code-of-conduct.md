# 工作注意事項

## 學業優先

**學業優先。享受你的大學生活。**

這份工作是圍繞你的學業而設，而不是相反。只預訂自己確實能夠出席的更份；當學業
需要時間時，請及早放棄更份。

## 五項要求

::: tip 團隊對你的期望
- **誠實（Honesty）**
- **自律（Self-discipline）**
- **責任感（Responsibility）**
- **時間管理（Time management）**
- **互相尊重（Respect each other）**
:::

## 佩戴工作證

當值期間必須佩戴 ITSC Student Helper 工作證。用戶需要知道你的身分，職員亦需要
知道你有權出現在該處。

## 請假

若無法出席已預訂的更份：

1. **在 WhatsApp 群組發訊息**，格式如下：

   ```
   Leave
   Name: Homan
   Date: 15/1/2025
   Time: 10:30-12:30
   Duty: printer check
   Reason: sickness
   ```

2. **自行從 [luhelperduty.online](https://luhelperduty.online) 移除你的更份紀錄。**

兩個步驟缺一不可 —— 只發訊息並不會釋放該更份。

## 接手他人的更份

當其他助理發出請假訊息而你可以接手時：

1. **在 WhatsApp 群組回覆**（例如「i can take」）。
2. **在 [luhelperduty.online](https://luhelperduty.online) 預訂該更份紀錄。**

## 櫃檯整潔

所有物品都必須放回原位，保持整齊清潔。

- 坐過的椅子要推回原位。
- 工作證放回抽屜櫃。
- 櫃檯工作站及電話保持你到達時的狀態。

## 歸還鎖匙及物資

- **Ricoh 打印機鎖匙**必須歸還到你取用的位置。
- 當值袋及其內容物（工作證、咪高峰、咪套、音訊 CD、電池）須放回 LCH206A 或
  MB202。
- 外借器材必須連同所有配件送回儲物室。
