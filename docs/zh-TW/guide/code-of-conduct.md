# 工作注意事項

## 學業優先

**學業優先。享受你的大學生活。**

這份工作是圍繞你的學業而設，而不是相反。只預訂自己確實能夠出席的更份；當學業
需要時間時，請及早放棄更份。

## 團隊期望

::: tip 團隊對你的要求
**誠實 · 自律 · 責任感 · 時間管理 · 溝通能力 · 互相尊重**
:::

## 應做與不應做

| 應做（Do） | 不應做（Don't） |
| --- | --- |
| **誠實**（Honest） | **接更或請假而不發訊息** |
| **準時**（Punctual） | **無故缺席** |
| **樂於助人**（Helpful） | **太遲才發請假訊息** |
| **有禮**（Polite） | **未做檢查就提交報告** |
| **每日至少查看一次 WhatsApp 群組** | **遲簽到或早簽退** |

::: danger 絕不提交沒有做過的報告
未做檢查就提交檢查結果，是唯一一件會摧毀整個制度價值的事 —— 那份報告是 ITSC
唯一能夠得知房間是否準備妥當的訊號。
:::

即使只是提早 15 分鐘簽退，也會被視為違規，而非「差不多」。

## 工作證明（Work Evidence）

各項檢查職務都要求上傳**相片**作為工作證明。

| 職務 | 相片欄位 |
| --- | --- |
| 早上檢查 | **必填** |
| 課室檢查 | 有此欄（Work-Evidence，第 26 題） |
| 電腦室檢查 | 選填 |
| 打印機檢查 | 選填 |

::: warning 怎樣才算有效的相片
必須顯示**時間**及**現場環境** —— 不能只是自拍。建議做法：拍下開著的鏡頭、
自己，以及房間的狀況。
:::

此要求是在有助理簽到後離開去吃早餐之後才引入的。ITSC 本來就能查閱登入紀錄；
相片只是作為簡單的實際證明，表格其餘部分仍然建基於信任。

## 佩戴工作證

當值期間必須佩戴 ITSC Student Helper 工作證。用戶需要知道你的身分，職員亦需要
知道你有權出現在該處。

## 請假

若無法出席已預訂的更份：

1. **在 WhatsApp 群組發訊息**，格式如下：

   ```
   Leave
   Name: Homan
   Date: 15/1/2025
   Time: 10:30-12:30
   Duty: printer check
   Reason: sickness
   ```

2. **自行從 [luhelperduty.online](https://luhelperduty.online) 移除你的更份紀錄。**

兩個步驟缺一不可 —— 只發訊息並不會釋放該更份。而且要盡早發出；太遲的請假訊息
造成的困擾，與不發訊息相差無幾。

![WhatsApp 群組中的請假訊息](/images/whatsapp-leave.jpg)
*群組中的請假訊息*

## 接手他人的更份

1. **在 WhatsApp 群組回覆**（例如「i can take」）。
2. **在 [luhelperduty.online](https://luhelperduty.online) 預訂該更份紀錄。**

![回覆接手更份](/images/whatsapp-cover.jpg)
*在群組回覆，然後自行預訂該更份*

## 櫃檯整潔

所有物品都必須放回原位，保持整齊清潔。

- 坐過的椅子要推回原位。
- 工作證放回抽屜櫃。
- 櫃檯工作站及電話保持你到達時的狀態。

![櫃檯的工作證抽屜](/images/badge-drawer.jpg)
*工作證要放回抽屜櫃，不要帶走*

## 檢查完離開房間之前

- **關閉所有你檢查過的電腦。**
- **關閉投影機及實物投影機**，並關掉控制面板。
- **留一盞燈開著。**

## 歸還鎖匙及物資

- **Ricoh 打印機鎖匙**必須歸還到你取用的位置，並重新鎖好打印機。
- 當值袋及其內容物（工作證、咪高峰、咪套、音訊 CD、電池）須放回 LCH206A 或
  MB202。
- 外借器材必須連同所有配件送回儲物室。
