# 聯絡與升級處理

::: info 待補充
本頁是範本。在本指南正式投入使用之前，請與主管一同填上真實的姓名、內線及聯絡
渠道 —— 並持續保持準確，因為出事時大家會打開的就是這一頁。
:::

## 須立即升級處理的情況

- 整個電腦室、整棟大樓或整項服務中斷
- 任何涉及帳戶權限、保安，或懷疑帳戶被入侵的事宜
- 可能有資料遺失
- 器材損壞、遺失或被盜
- 用戶動怒、作出威脅，或想要提出正式投訴
- 任何你未受過訓練的事項

## 15 分鐘後須升級處理的情況

- 單一用戶的問題毫無實質進展
- 你正處理一宗長個案，同時人龍不斷變長
- 所需的修復方式超出你的授權範圍

## 升級時須提供的資料

1. **誰** —— 用戶姓名及聯絡方式，以及他是否仍在現場等候。
2. **何處** —— 房號、機器主機名稱或資產編號。
3. **什麼** —— 徵狀，以及一字不漏的錯誤訊息。
4. **範圍** —— 一位用戶、一部機器，還是所有人。
5. **已試過** —— 你已經做過什麼，以及結果有何變化。
6. **緊急程度** —— 是否正在阻礙一節課堂或一個死線。
