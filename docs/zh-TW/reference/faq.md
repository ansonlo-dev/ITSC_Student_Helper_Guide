# 常見問題

用戶最常問的問題與簡短答案。在當值時真正倚賴這一頁之前，請先補上校內的實際資料。

## 帳戶

### 用戶忘記密碼，我可以幫他重設嗎？

先用學生證或職員證核實身分，然後引導他們完成 **自助** 重設。切勿代為輸入密碼，
也切勿為未親身核實身分的人重設帳戶。詳見[帳戶與密碼](/zh-TW/duties/accounts)。

### 用戶剛重設完密碼又再被鎖定，為什麼？

幾乎一定是有裝置仍在嘗試舊密碼 —— 通常是手機的郵件程式或已儲存的 Wi-Fi 設定檔。
請他們在每一部裝置上更新已儲存的密碼。

### 用戶叫我幫他查看電郵。

不可以。切勿登入或閱讀任何人的郵箱。應協助他們自己登入查看。

## Wi-Fi 與網絡

### 用戶連不上校園 Wi-Fi。

檢查：網絡名稱是否正確、用戶名格式是否正確、最近有否更改密碼，以及裝置上是否有
舊的設定檔需要移除後重新加入。若同一時間有多名用戶在同一網絡失敗，應升級處理。

### 我可以幫用戶增加配額嗎？

不可以。配額調整須升級交由全職職員處理。

## 列印

### 用戶說什麼都沒印出來。

檢查是哪一部打印機、檢查列印佇列、檢查是否需要在機器上釋放列印工作，以及檢查
配額。釋放之前先清除重複的工作。詳見[列印服務](/zh-TW/duties/printing)。

## 電腦室

### 用戶存放在電腦室桌面的檔案不見了。

電腦室的工作站可能會在重啟後重設。若檔案已經消失，通常無法救回 —— 請坦白說明，
並告訴用戶下次應該存放在哪裡。

### 有機器壞了，我應該怎樣做？

貼上「暫停服務」標示，記下主機名稱或資產編號及房號，然後呈報。詳見
[電腦室支援](/zh-TW/duties/lab-support)。

## 課室

### 老師在課堂中途來電說投影機有問題。

立即前往。檢查電源、輸入訊號源及線材，然後試 `Win`+`P`／鏡像輸出。若預計需時超過
一兩分鐘，先提供替代方案。詳見[影音及課室設備](/zh-TW/duties/av-equipment)。

## 工作本身

### 如果我不知道答案怎麼辦？

坦白說出來，然後去弄清楚。「我不太確定，讓我問一下同事」是完全專業的回答，遠遠
勝過亂猜。

### 如果我弄壞了東西怎麼辦？

立即告訴職員。問題被隱瞞之後，代價會高得多。
