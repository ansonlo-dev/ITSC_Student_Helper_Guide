# 系統與連結

## 核心系統

| 系統 | 網址 | 用戶名稱 | 密碼 |
| --- | --- | --- | --- |
| **更份預訂系統** | [helperduty.top](https://helperduty.top) | 你的用戶名稱 | 你的**學生編號** |
| **簽到／簽退** | [ics.ln.edu.hk/helper](https://ics.ln.edu.hk/helper) | 你的用戶名稱 | 你的 **LU 密碼** |

::: warning 兩個系統，兩個不同密碼
預訂系統用**學生編號**；簽到系統用 **LU 密碼**。混淆這兩者是最常見的登入失敗
原因。
:::

| 系統 | 可以在哪裡使用 |
| --- | --- |
| **更份預訂系統** | 只限校園 Wi-Fi，或校外經 **LUVPN** |
| **簽到／簽退** | 必須身處校園並連接校園網絡 —— 宿舍助理要走到最近的課室大樓 |

::: danger 預訂系統不可外傳
它是一個**獨立的私人資料庫**，並沒有與 LU 主要系統連接。**不要向大學其他部門
（例如 OSA）透露這個系統的存在。**
:::

## 沒有某些設備的房間

在你標記「Not ok」之前，值得先知道：

| 房間 | 沒有的設備 |
| --- | --- |
| SEK105 | 沒有光碟機、沒有打印機 |
| LCH413 | 沒有打印機 |
| LYH308 | 沒有電腦 —— 只需檢查燈光同電視 |
| LKK107、LKK108、LKK110 | 沒有無線咪，只有有線咪，而這是正常的 |
| MBG11 | 觸控面板上沒有實物投影機的選項 —— 用電腦的 Camera App |
| LKK 新翼房間 | 沒有腳架（鏡頭固定在幕牆上） |
| LKKG0X | 無法在 Windows Camera App 更改鏡頭設定 —— 要用 Zoom |

## 各有不同的房間

以下每一項，都曾經被不知情的助理當成故障呈報：

| 房間 | 有甚麼不同 |
| --- | --- |
| **MBG06** | 該房間的咪是**教師講台上的數碼咪**，**不支援**紅外線咪 —— 紅外線咪沒有聲不是故障。 |
| **LKK 地下** | 鏡頭**固定在牆上**，不是枱面的小鏡頭。它在電腦上顯示為 **「Black Magic」**，畫面角度在**控制面板**上切換。 |
| **LCH206、LCH209、LCH213** | **舊款影音系統。** 實物投影機無法直接輸出到投影機 —— 改為在**電腦的 Camera App** 裡當成 webcam 開啟。 |
| **LYH319／LYH320** | 由影音組設定為**合併模式（combined mode）** —— 一個控制面板同時服務兩間房。 |
| **WYL314** | 是**會議室**；以一部手提電腦代替教師機。 |
| **LCH416** | 只能以 **LU 卡拍卡**進入，助理沒有權限 —— 標記 **Room closed**。 |
| **LCH113** | **根本沒有這間課室。** 地圖上 LCH113 的位置，在 LCH 一樓其實是一間掛著「Do not enter」的科學實驗室。若它出現在你的分配表上，標記 **Room closed** 並告知 Paul。 |
| **SEKG02、LCH206A 彩色影印機** | 2026 年 9 月換成需要登入的 **Ricoh C6010** —— 見[打印機檢查](/zh-TW/duties/printing#新款彩色影印機)。 |
