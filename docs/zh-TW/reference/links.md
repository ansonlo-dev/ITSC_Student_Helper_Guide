# 系統與連結

## 核心系統

| 系統 | 網址 | 用戶名稱 | 密碼 |
| --- | --- | --- | --- |
| **更份預訂系統** | [luhelperduty.online](https://luhelperduty.online) | 你的 CNA | 你的**學生編號** |
| **簽到／簽退** | [ics.ln.edu.hk/helper](https://ics.ln.edu.hk/helper) | 你的 CNA | 你的 **LU 密碼** |

::: warning 兩個系統，兩個不同密碼
預訂系統用**學生編號**；簽到系統用 **LU 密碼**。混淆這兩者是最常見的登入失敗
原因。
:::
