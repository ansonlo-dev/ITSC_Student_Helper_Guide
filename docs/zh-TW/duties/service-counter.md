# 服務櫃檯

櫃檯是 ITSC 的門面。你遇到的用戶大多已經有點不耐煩 —— 一個冷靜、有條理的櫃檯，
在你動手碰電腦之前就已經解決了一半問題。

## 開櫃檯

1. 簽到並閱讀交接筆記。
2. 檢查櫃檯工作站、電話及標籤打印機是否正常。
3. 補充表格及外借物品。
4. 查看有沒有需要向用戶轉達的服務公告（停機、維修時段）。

## 處理親臨個案

::: tip 四條問題
1. 你原本想做什麼？
2. 結果發生了什麼？
3. 上一次正常運作是什麼時候？
4. 你已經試過什麼方法？
:::

然後：

1. **核實身分** —— 涉及帳戶的個案須查看學生證或職員證。
2. **分流** —— 這件事能否在櫃檯幾分鐘內解決？
3. **解決或升級** —— 不要一邊讓用戶等，一邊自己在試。
4. **記錄個案**：用戶報告的問題、你做過什麼、最終結果。

## 應付人龍

- 有人加入隊伍時要打個招呼，即使你暫時未能招呼他們。
- 在公平的前提下，可在長個案之間穿插處理快速事項（領取物品、簡單查詢）。
- 若等候時間較長，坦白說出大概要等多久 —— 誠實的估算勝過沉默。
- 人龍持續變長時，召喚另一位助理或主管幫忙。

## 接聽電話

- 用一致的問候語接聽：部門名稱、你的名字、然後提供協助。
- 在開始排查之前，先取得來電者的姓名、聯絡方式及回電號碼。
- 複述一次問題，確認你理解無誤。
- 若必須轉接，要告訴來電者你會轉接給誰，以及原因。

## 收櫃檯

1. 完成或交接未結個案。
2. 撰寫交接筆記。
3. 收回外借物品，貴重物品鎖好。
4. 登出共用帳戶；鎖上工作站。
5. 簽退。
