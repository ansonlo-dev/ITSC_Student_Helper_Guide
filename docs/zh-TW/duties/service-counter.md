# 櫃檯當值

## 地點與時間

**工作地點：MB402** —— ITSC 服務櫃檯。

![ITSC 服務櫃檯](/images/counter.jpg)
*ITSC 服務櫃檯，MB402*

| | 櫃檯服務時間 |
| --- | --- |
| 平日 | 星期一至五，上午 8:30 – 下午 6:30 |
| 考試／學期假 | 星期一至五，上午 9:00 – 下午 5:30 |

**星期六、日及公眾假期休息。** 助理坐在 **ITC 櫃檯後方、全職職員旁邊** ——
所以要轉介查詢，通常只是轉身問一問身邊的同事。

## 職務範圍

1. 處理用戶透過**電話或親臨**提出的查詢
2. **器材外借** —— 詳見[器材外借](/zh-TW/duties/av-equipment)
3. 聽取留言、接收送貨，以及保持櫃檯整潔

常見查詢類別：服務熱線、用戶帳戶、器材外借、網絡、雙重驗證（2FA），以及其他
臨時事項。

::: tip 打印相關的查詢有專屬一頁
「邊度可以打彩色？」「A3 幾錢？」「可唔可以用自己部電腦打印？」——
[打印機一覽](/zh-TW/facilities/printers)全部有答案，連同收費與每部機的位址。
:::

::: tip 大部分查詢只有兩個題目
**基本用戶查詢中，八至九成都與 LUVPN 及 Duo 雙重驗證（2FA）有關。** 先把這兩項
學會。櫃檯常用連結頁上的知識庫連結，可以帶用戶完成 **Duo 2FA 重新啟用**（遺失
或更換手機）以及**在中國內地及海外設定 LUVPN** —— 見
[帳戶與 2FA 查詢](/zh-TW/duties/accounts)。
:::

## 熱線

熱線系統為 **Cisco Finesse**。

![Cisco Finesse 登入畫面](/images/finesse-login.jpg)
*Cisco Finesse —— 用戶名稱與分機號碼相同*

### 接聽來電

先專業地介紹自己：

> 「Good morning, ITC, my name is [Name], how may I help you?」

用心聆聽，注意語速適中、語氣有禮，並且練習**把冗長複雜的描述整理成簡潔、清晰、
可以行動的摘要** —— 這個摘要就是你要填進表格、以及交給當值職員的內容。

::: danger 黃金定律 —— 絕不猜測
**絕不猜測，也絕不向用戶提供未經核實或虛構的資料。** 如果你不知道答案，請保持
冷靜，記下用戶的**姓名、學生／職員編號、位置及聯絡電話**，然後把資料交給坐在你
旁邊的全職職員處理。
:::

開始排查之前，先取得填表所需的資料：**姓名、電郵、編號、內線或電話號碼、部門
及位置**。事後單靠記憶是填不回那份紀錄的。

::: tip 緊急與非緊急
先做分流。一節正在進行、投影機壞了的課堂屬緊急，要立即交給當值職員；一般
「該怎樣做……」的查詢可以在櫃檯解答或記錄後跟進。轉交時要說明屬於哪一類。
:::

## 留言信箱（Voice Mail）

![留言信箱登入畫面](/images/voicemail-login.jpg)
*熱線留言信箱登入*

當值期間要查聽留言，並**取回服務時間以外留下的錄音**。每一則都要當作一般事故
記錄，填入查詢表格 —— 與處理現場來電的做法完全一樣。

::: warning 查聽留言是櫃檯每一更的份內事
簽到時同簽退前各查一次，是櫃檯當值者應做的事 —— 群組裡幾乎每朝都會提，漏做是會被
點名跟進的。漏聽一則留言，即是有一位在服務時間以外致電的用戶，完全等不到回覆。
:::

::: danger 共用登入資料
以上熱線及留言信箱的登入資料屬團隊共用。請勿外傳至學生助理團隊以外，亦不要
把它們寫低放在櫃檯。
:::

## 記錄查詢

**每一宗**遇到的用戶查詢都要記錄，並透過
**Issue Received by ITSC Student Helper** 表格提交：

**<https://forms.office.com/r/30WbQbDCSF>**

| # | 題目 | 注意事項 |
| --- | --- | --- |
| 1 | **Student Helper Name** | 你 |
| 2 | **Staff/Student Name** | 問清楚串法，不要靠估 |
| 3 | **Staff/Student Email** | 職員日後跟進的途徑 —— 要向對方複述確認 |
| 4 | **Staff/Student ID** | |
| 5 | **Staff/Student Extension/Phone Number** | 電話查詢要先取得回電號碼，才開始排查 |
| 6 | **Staff/Student Department** | |
| 7 | **Staff/Student Location** | 要寫房號，不是「樓上那間電腦室」 |
| 8 | **Issue Summary** | **最多 100 字** —— 當成一行標題來寫 |
| 9 | **Issue Detail** | **最少 20 字** —— 徵狀、一字不漏的錯誤訊息，以及你已試過什麼 |
| 10 | **Status** | 見下方 |

**Status 選項：**

- Followed up by **User Services Team** Staff（用戶服務組職員跟進）
- Followed up by **AV Team** Staff（影音組職員跟進）
- **Fixed by Student Helper**（學生助理已解決）
- **Not fixed**（未解決）

![Issue Received by ITSC Student Helper 表格](/images/issue-form.jpg)
*查詢表格 —— 每一宗親臨及來電都要記錄*

::: warning 如實選擇狀態
「Not fixed」是一個有效而且有用的答案。用戶不滿意地離開卻標記為已解決，只會令
整個跟進流程斷掉。留言或網上訊息如果**完全沒有留下聯絡方法**，一樣要記錄，並標記
為未能解決 —— 它仍然是一筆紀錄。
:::

::: danger 每一通電話都要有紀錄
**一通電話，一份提交。** 不是放工前寫一個總結，也不是「今日冇特別」—— 櫃檯接到的
每一通電話，都要趁你還記得細節的時候寫進這張表格。
:::

::: tip 不確定就發問
任何不確定的事情，都應該詢問全職職員。
:::

## 櫃檯的器材外借

- **先確認借用資格** —— 只有**在職職員及在學學生**可以借用，**校友一律不可
  借用**。
- **掃描器材上的 QR code**，或把標籤號碼輸入資料庫，然後按 **Save Booking**
  記錄該筆交易。
- **一定要按 Check-Out** —— 否則系統上根本沒有這筆借出紀錄。
- **歸還時要逐件檢查**：無線簡報器的 USB 接收器還在嗎？手提電腦能否開機？
  配件是否齊全？
- 要清楚**每件器材是什麼樣子、擺放在哪裡**，以及用戶需要哪一款**咪高峰**。
- 用**條碼掃描器**，不要人手輸入編號。

::: danger 一定要當著借用人面前測試
所有電子類外借器材 —— 手提電腦、投影機、電視螢幕 —— 都必須**當著借用人面前開機
並確認運作正常，才讓對方拿走。** 這樣才能避免器材損壞後被說成「借的時候已經
壞了」。
:::

完整流程見[器材外借](/zh-TW/duties/av-equipment)。

## 送貨

需要簽收的送貨，請入內找職員處理 —— 不要自行代 ITSC 簽收貨物。

## 其他櫃檯工作

- **助理工作證** —— 派發及收回，存放在抽屜櫃內。
- **Counter notebook** —— 櫃檯交接紀錄簿；要閱讀，也要補充。
- 要知道**如何指引別人前往人力資源處**，這是櫃檯常見的問題。
- `Alt`+`R` 可登出櫃檯工作站。

### 無人認領的失物

在櫃檯交來的失物，最常見是**香港身分證、學生證，以及銀包**。要登記並交給職員
處理 —— 不要把貴重物品留在櫃檯枱面。

## 櫃檯貼士

1. 仔細聆聽對方的問題，理解他們的**真實情況**。
2. 留意自己說話的**速度與語氣**。
3. 評估事情的**緊急程度**。
4. 向 ITSC 同事求助時，先講清楚該查詢是**親臨還是電話**。

更多內容見[與用戶溝通](/zh-TW/tips/communication)。

## 櫃檯檢查（Counter Check）

簽退之前，提交 **Counter Checklist** 表格（常用連結頁的 **Counter Check**）：

| # | 題目 | 選項 |
| --- | --- | --- |
| 1 | **Your name** | 你的名字 |
| 2 | **Check SPSS & AMOS Status** | Ok／Not ok |
| 3 | **Check SDL** | Ok／Not ok |
| 4 | **MB402 Printer Keys Exist or Not** | Exist／Not exist |
| 5 | **MB402 Badge Exist or Not** | Exist／Not exist |
| 6 | **Remark** | 自由填寫 |

![Counter Checklist 表格](/images/counter-checklist.jpg)
*Counter Checklist*

::: warning 櫃檯不可留下敏感資料
交更時要保持櫃檯整潔、專業。**不可有任何個人文件或敏感資料外露** —— 桌面上不
可以，螢幕上也不可以。簽退前確認打印機鎖匙及後備工作證已放回櫃內；第 4、5 題
問的就是這件事。
:::

第 2、3 題在櫃檯的機器上檢查 —— MB402 裝有 SDL。第 4、5 題與
[打印機檢查](/zh-TW/duties/printing#物品存在檢查)表格上點算的是同一套鎖匙及
工作證；要實際點算，不要假設。
