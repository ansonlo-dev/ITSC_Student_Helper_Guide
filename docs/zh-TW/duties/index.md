# 職務總覽

學生助理的職務主要分為幾個經常出現的範疇。第一次被編排到某項職務前，請先閱讀
以下對應的頁面 —— 每一頁都是可直接使用的檢查清單。

| 職務 | 涵蓋範圍 |
| --- | --- |
| [服務櫃檯](/zh-TW/duties/service-counter) | 招呼用戶、記錄個案、前線分流 |
| [電腦室支援](/zh-TW/duties/lab-support) | 電腦室巡查、工作站故障、軟件問題 |
| [影音及課室設備](/zh-TW/duties/av-equipment) | 投影機、咪高峰、課堂錄影、器材外借 |
| [帳戶與密碼](/zh-TW/duties/accounts) | 重設密碼、啟用帳戶、多重驗證 —— 以及其界限 |
| [列印服務](/zh-TW/duties/printing) | 列印佇列、配額、卡紙、耗材 |

## 每宗個案的共通流程

無論是哪一項職務，流程都是一樣的：

1. **招呼** 用戶，弄清楚他們真正需要什麼。
2. **核實** 身分 —— 若個案涉及帳戶或個人資料。
3. **診斷** —— 使用[故障排查手冊](/zh-TW/tips/troubleshooting)。
4. **解決** —— 若在你的職權範圍內。
5. **升級** —— 若超出職權範圍，詳見[聯絡與升級處理](/zh-TW/reference/contacts)。
6. **記錄** 處理經過，讓下一位同事掌握來龍去脈。

## 認清自己的界限

::: danger 一律升級，切勿自行摸索
若個案涉及帳戶權限、保安、資料遺失，或任何你未受過訓練的事項，請交由全職職員
處理。亂猜所花的時間，遠比開口問要多得多。
:::
