# 電腦室支援

## 例行巡查

開更時巡視電腦室一次，其後定時再巡。

::: tip 巡查檢查清單
- 每部工作站都能開機並進入登入畫面
- 螢幕、鍵盤、滑鼠及各種線材齊全並已接妥
- 沒有工作站在登入狀態下無人看管
- 椅子推回原位，枱面沒有垃圾
- 打印機有紙；沒有錯誤燈亮起
- 冷氣及照明運作正常
- 故障機器已貼上「暫停服務」標示並已呈報
:::

## 常見工作站故障

| 徵狀 | 首先檢查 |
| --- | --- |
| 沒有電源 | 牆上開關、電源線兩端、拖板 |
| 沒有畫面 | 螢幕電源、視訊線是否插實、換另一個插口 |
| 當機 | 先等一會，再強制重啟；記下是哪個程式導致 |
| 無法登入 | Caps Lock、用戶名格式、網線、看看其他機器是否同樣情況 |
| 沒有網絡 | 網線是否插實、指示燈、測試同一交換器上的另一部機 |
| 機器很慢 | 檢查是否有卡住的更新或失控程序；重啟 |
| 軟件不見了或無法開啟 | 確認該軟件本應在這個系統映像中；若不是則呈報 |

::: warning 一部機還是全部機？
必須先確認故障只影響一部工作站，還是整個電腦室。全室性的故障屬於網絡或伺服器
問題 —— 應立即升級處理，而不是逐部電腦去排查。
:::

## 呈報故障機器

1. 清楚貼上標示，讓用戶避開。
2. 記下機器的資產編號或主機名稱、房號，以及徵狀。
3. 註明你已經試過什麼方法。
4. 在故障系統中登記；若電腦室繁忙或即將有課堂使用，同時通知職員。

## 在電腦室協助用戶

- 未經同意，不要碰用戶的鍵盤或滑鼠。
- 盡可能引導用戶自己操作 —— 可以省下他下次再來的時間。
- 提醒用戶在任何重啟前先儲存工作。
- 提醒用戶電腦室的工作站可能會在重啟後重設：檔案必須儲存到個人或雲端儲存空間，
  切勿存放在本機桌面。

## 課堂預約期間

- 查看你當更時段的預約時間表。
- 在預約課堂開始前先到電腦室，確認教學電腦及投影機運作正常。
- 課堂進行期間不要大聲排查故障；請等待適當時機，或與用戶移步室外處理。
