## XClass

需要登入超過 20 部電腦的電腦室都裝有 **XClass**，可以一次過檢查整個電腦室。
在教師電腦上你可以：

- 集中控制所有學生電腦
- 多選或全選電腦，**一鍵開機或關機**
- 查看監控畫面，知道哪些螢幕已開啟

**登入資料：**

| 欄位 | 內容 |
| --- | --- |
| Log on name | 你自己的用戶名稱 |
| Password | 你自己的密碼 |
| Domain | `LNDAXUE` |

::: info 已安裝 XClass 的房間
LBY301、LBY303、LCH201、LCH202、LCH206、LCH209、MB202、SEKG03、SEK105。
:::

管理員可以看到每位學生在哪一部機器登入及登出 —— 但看不到在機器上做過什麼。

::: tip 核對編號
要核對 XClass 上的編號與實體電腦編號是否一致 —— 曾經發現位置對不上。未安裝
XClass 的房間就要逐部處理；用 `Alt`+`F4` 再按 `Enter` 是最快的關機方式。
:::

### 枱面玻璃隔板

設有玻璃隔板的電腦室，亦要檢查**枱面玻璃隔板**。學生曾報告標籤缺失或螢幕無法
開啟 —— 遇到這些情況要**拍照**並上傳。

### 工作證明

此表格的相片上傳欄位為**選填**（早上檢查則是必填），但只要你呈報故障就應該
上傳 —— 一張相片能說清楚「not ok」到底是什麼樣子。

## 鏡頭檢查方法

兩種方法：

1. **Zoom** —— 登入後 **設定 → 視頻**，可以同時看到 C930 及 C925 兩款鏡頭。
   Paul 已在群組發放示範影片。
2. **系統內置的 Windows Camera App。**

::: warning LKKG0X —— 只能用 Zoom
LKKG0X 無法在系統 Camera App 更改鏡頭設定，這兩間房必須用 Zoom 檢查。
:::

最常見的誤報，是有人把**鏡頭蓋**關上或把鏡頭撥開，令畫面全黑。呈報之前先檢查
鏡頭蓋。

## 常見故障

- 投影模式未設為 **Duplicate／Extend**
- 電源插頭被拔出
- 螢幕線鬆脫
- 觸控面板音量被靜音或調到最低
- 鏡頭蓋沒有打開

## 離開之前

::: tip 收尾流程
1. **關閉所有你檢查過的電腦** —— 有 XClass 就用 XClass，否則逐部按 `Alt`+`F4`、
   `Enter`。
2. **關閉投影機及實物投影機。**
3. **關掉控制面板。**
4. **留一盞燈開著。**
:::
