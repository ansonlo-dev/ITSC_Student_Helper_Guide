請查看預訂日曆確認當晚的分配。

## 每部機器要檢查什麼

- 電腦能開機並進入登入畫面
- 能夠成功登入
- 螢幕、鍵盤、滑鼠及線材齊全並已接妥
- 教師電腦能成功輸出到課室的顯示設備

## 提交結果

從檢查表連結頁開啟 **→ Computer Lab Check ←**，提交
**Computer Lab Checklist** 表格：

1. **Your name** —— 你的名字
2. **Which Computer Lab You Check?** —— 從下拉選單選出你負責的範圍，例如
   「SEKG03 Teacher PC, No.01-20」

### 呈報問題的格式

檢查期間發現的問題，一律以此格式記錄：

```
Machine Name - Issue
```

例如：

```
No.15 PC - Cannot Login
```

要寫得具體 —— 機器編號加上實際發生的情況。
