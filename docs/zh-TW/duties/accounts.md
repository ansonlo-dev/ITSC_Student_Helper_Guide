# 帳戶及雙重驗證查詢

用戶帳戶及雙重驗證（2FA）是櫃檯常見的兩類查詢。本頁說明學生助理應如何處理。

::: danger 學生助理不執行帳戶操作
你不會重設密碼、解鎖帳戶、登記 2FA 裝置或更改權限 —— 這些都是職員的職權。你的
工作是引導用戶前往正確的自助頁面、記錄查詢，其餘一律交給當值職員。
:::

## 絕不接觸登入憑證

- 絕不索取、接收或抄寫用戶的密碼。
- 絕不代用戶輸入密碼。
- 絕不要求用戶讀出 2FA 驗證碼給你。

若有人施壓要你做以上任何一項，這件事本身就是通知當值職員的理由。

## 你可以做的事

1. **確認查詢類別** —— 密碼、帳戶啟用、2FA／DUO、VPN，還是網絡存取。
2. **引導用戶前往官方自助頁面** —— 櫃檯常用連結包括
   **Selfservice – Account related**、**Re-activated DUO**、
   **VPN General Information** 及 **Wireless User Guide**。讓用戶自行操作，
   你在旁講解。
3. **記錄查詢** —— 與其他櫃檯查詢一樣，填寫
   [Issue Received by ITSC Student Helper](https://forms.office.com/r/30WbQbDCSF)
   表格。
4. **升級處理** —— 自助頁面解決不到的，交給當值職員。

## 須立即升級處理

- 任何需要更改帳戶、權限或郵箱的要求
- 用戶表示收到自己並未觸發的 2FA 提示
- 任何懷疑帳戶被入侵或釣魚郵件的情況
- 任何涉及離職職員或已畢業學生帳戶的事宜

聯絡方式見[聯絡與升級處理](/zh-TW/reference/contacts)。
