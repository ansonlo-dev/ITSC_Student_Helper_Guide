# 帳戶與密碼

這是規則最嚴格的一項職務。帳戶存取權是 ITSC 所掌管最敏感的東西，而社交工程攻擊
通常就從這裡開始。

::: danger 不容妥協的底線
- **絕不**索取或接收用戶的密碼，無論是面對面、電話還是書面。
- **絕不**代用戶輸入密碼。讓用戶自行輸入，期間別過頭。
- **絕不**為未按核准程序核實身分的人重設密碼。
- **絕不**因為用戶趕時間、職級高，或者是朋友，就「破例一次」為其重設。

若有人施壓要你違反以上任何一項，這件事本身就是升級處理的理由。
:::

## 核實身分

在處理任何與帳戶相關的事情之前：

1. 要求出示有效的學生證或職員證。
2. 核對相片及姓名與眼前的人相符。
3. 核對姓名與將被變更的帳戶相符。

若為電話或電郵提出的要求，**不要**自行核實身分 —— 請依照核准的遠端核實程序處理，
或請用戶親身前來。

## 協助用戶自行重設密碼

目標永遠是讓用戶自助完成。你的角色是引導，而不是代勞：

1. 引導用戶前往官方的密碼重設網頁。
2. 一邊講解步驟，一邊讓用戶自己輸入。
3. 在用戶選擇新密碼之前，提醒他們密碼規則。
4. 請用戶在原本無法使用的服務上確認新密碼有效 —— 用電郵或入門網站測試就很合適。
5. 提醒用戶更新手機及其他裝置上已儲存的密碼，否則反覆的登入失敗可能導致帳戶
   再次被鎖定。

## 帳戶被鎖定

帳戶被鎖定通常是因為某處仍有裝置在嘗試使用舊密碼 —— 最常見的是手機的郵件程式或
已儲存的 Wi-Fi 設定檔。詢問用戶使用哪些裝置，並請他們逐一更新或移除已儲存的密碼。

## 多重驗證（MFA）

- 可以協助用戶登記新裝置，但絕不代用戶完成登記。
- 絕不要求用戶讀出多重驗證碼給你。
- 若用戶表示收到自己並未觸發的驗證提示，須當作帳戶可能已被入侵，立即升級處理。

## 釣魚郵件呈報

若用戶帶著一封可疑電郵前來：

1. 不要點擊郵件中的任何內容。
2. 詢問用戶有否輸入過登入資料或開啟過附件。
3. 若有，立即當作帳戶可能已被入侵並升級處理。
4. 透過官方的釣魚郵件呈報渠道舉報該郵件。

## 學生助理職權範圍以外

以下全部須升級處理：

- 開立、刪除、重新命名或延長帳戶
- 變更群組成員身分或權限
- 郵箱委派或共用郵箱存取權
- 任何涉及離職職員或已畢業學生帳戶的事宜
- 任何懷疑帳戶被入侵的情況
