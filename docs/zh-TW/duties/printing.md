## Ricoh 打印機鎖匙

以下情況需要用到鎖匙：

1. 清除**卡紙**
2. **八達通卡卡住**在讀卡器內
3. **補充紙張**

::: warning 鎖好並歸還鎖匙
完成後要重新鎖好打印機，並把鎖匙歸還到**你取用的位置**。表格會檢查鎖匙是否
已放回。
:::

## 機器上要檢查什麼

- **讀卡器** —— 指示燈必須是**綠色**。
- **紙盤** —— 每個紙盤都要推到最入，聽到「卡」一聲。紙盤未完全歸位，狀態畫面
  不會顯示真實的剩餘紙量。
- **Machine Information 畫面** —— 以百分比區間顯示 K / C / M / Y 碳粉存量，
  以及 Tray 1、Tray 2、Tray 3 及 Bypass Tray 的紙張存量與紙張尺寸。

## 何時補充耗材

| 耗材 | 補充時機 |
| --- | --- |
| **碳粉／墨** | 打印機**提示存量偏低**時 |
| **紙張** | 紙盤**低於 50%** 時 |

## 紙張存量檢查（Paper Stock Check）

::: tip 只限第一節
**每日只有第一節打印機檢查需要做紙張存量檢查。** 表格會直接以 Yes／No 問你。
:::

點算儲存處剩餘的 **A4 及 A3 紙（箱裝）**，記下還有多少。第一次當值之前，先弄
清楚紙箱擺放在哪裡、包裝是什麼樣子。

## 表格

**Printer & Paper Stock Check**，從
**→ Printer Check & Paper Stock Check ←** 開啟。

### 打印機狀態

作答為 **Ok**／**Not ok**／**Room closed**／**Room in use**／*自行填寫*。

| 題目 | 表格上的註明 |
| --- | --- |
| **SEKG02 Color Printer** | |
| **SEKG02 B&W Printer** | *SEKG02 have 2 B&W Printer* |
| **LCH213 B&W Printer** | |
| **LCH206A Color Printer** | |
| **LCH206A B&W Printer** | *LCH206A have 1 B&W Printer* |
| **MB202 B&W Printer** | |

::: tip 「Room closed」及「Room in use」都是有效答案
應該如實選用，而不是留白或者猜一個「Ok」。MB202 於 17:00 關閉，所以第 3、4 節
理應記錄為 Room closed。
:::

### 物品存在檢查

作答為 **Exist**／**Not exist**／**Room closed**／*自行填寫*。表格上的數量就是
應有的數目 —— 要實際點算。

| 題目 | 數量 |
| --- | --- |
| **LCH206A Printer Keys Exist or Not** | 1 |
| **LCH206A Badge Exist or not** | 7 |
| **LCH206A IR Mics Exist or Not** | 7 |
| **LCH206A CD Exist or Not** | 7 |
| **MB402 Printer Keys Exist or Not** | 1 |
| **MB402 Badge Exist or Not** | 1 |

::: warning 要點算，不要望一眼算數
「Exist」的意思是所列數量全部齊備。七個工作證只剩六個，就應該填 **Not exist**
並加備註 —— 這樣才能當日就發現少了一支 IR mic，而不是一星期之後。
:::
