# 列印服務

列印是所有服務中親臨查詢最多的一項，而當中大部分都是那幾個相同的問題。

## 常見成因

| 用戶說 | 通常原因 |
| --- | --- |
| 「什麼都沒印出來」 | 送去了錯的打印機，或未在機器上釋放列印工作 |
| 「它說我沒有配額」 | 配額用完，或未增值 |
| 「印出來是白紙」 | 碳粉用完，或文件本身確實是空白 |
| 「一直印不完」 | 檔案太大，或佇列卡住 |
| 「印出來有間條／很淺色」 | 碳粉不足，或需要搖勻 |
| 「我的手提電腦印不到」 | 缺少驅動程式，或未連接校園網絡 |

## 標準處理次序

1. 確認列印工作 **送到了哪一部打印機**。
2. 檢查列印佇列 —— 工作是卡住、被暫停，還是其實已經印了？
3. 查看打印機本身的顯示屏有沒有錯誤（缺紙、碳粉、卡紙、離線）。
4. 檢查用戶的配額或餘額。
5. 請用戶重新送出 **一頁測試頁**，而不是整份文件再印一次。

::: warning 重複的列印工作
用戶見到沒有反應時，往往會連按幾次列印。釋放之前先清除多餘的工作，否則用戶會拿到
五份副本，而且五份都會扣配額。
:::

## 清除卡紙

1. 閱讀打印機顯示屏 —— 它會指出是哪道門、哪個紙盤。
2. 打開指示的門，用雙手 **順著出紙方向** 慢慢把紙拉出。
3. 不要撕破紙張；務必清走每一片碎紙，否則會再次卡紙。
4. 不要觸碰定影器 —— 它非常燙。
5. 關好所有門，讓打印機重設，然後印一張測試頁。
6. 若在同一位置再次卡紙，將該機暫停服務並呈報。

## 耗材

- 在紙盤用完之前就補紙，裝入前先把紙叠搧鬆。
- 不要裝紙超過紙盤的上限線。
- 碳粉：輕輕搖勻可以撐一陣，但仍應更換，不要放著讓它一直印出淺色文件。
- 及早呈報耗材不足 —— 不要等到斷供才處理。

## 配額與付款

冷靜地解釋配額制度；用戶經常誤以為那是故障。告訴他們在哪裡查看餘額、如何增值。
切勿自行調整配額 —— 應升級處理。

## 掃描與影印

- 掃描前先確認掃描檔要送去哪裡（電郵或網絡資料夾）。
- 提醒用戶從玻璃面板或送稿器取回原稿。
- 遺留在機器上的機密文件應交到服務櫃檯，不要閱讀，也不要丟棄。
