# 影音及課室設備

影音問題幾乎一律緊急：有一班學生正在等。這裡比任何地方都更講求速度和冷靜的
態度。

## 回應課室求助

1. 出發前先取得房號及確切徵狀。
2. 立即前往 —— 課堂正在流失時間。
3. 安靜進入，向老師打招呼，動手處理而不要一路解說。
4. 若無法短時間內修好，提供替代方案（後備手提電腦、改用其他輸入、轉到附近課室），
   同時升級處理。

## 投影機沒有畫面

按以下次序逐項檢查：

1. 投影機開了嗎？看燈泡／狀態指示燈，不要只看投影畫面。
2. 是否選對了 **輸入訊號源**（HDMI 1／2、VGA、無線）？
3. 線材兩端是否都插實？換一條線試試。
4. 在手提電腦上強制偵測顯示器，並設為 **同步顯示**：
   - Windows：`Win` + `P` → 同步顯示
   - macOS：系統設定 → 顯示器 → 鏡像輸出
5. 用一部確認正常的手提電腦測試，以區分是電腦問題還是課室問題。
6. 檢查該課室是否設有控制面板或矩陣切換器，需要選擇正確的預設模式。

::: tip 轉接頭
最多投訴其實源於 USB-C／HDMI／VGA 轉接頭。器材車上要備有後備轉接頭，先檢查轉接頭
再怪責課室設備。
:::

## 沒有聲音

1. 課室的音量旋鈕或擴音機有否調高、是否靜音？
2. 手提電腦音量有否調高、是否靜音？
3. 手提電腦是否選對了 **輸出裝置**（HDMI、內置喇叭，還是 USB 裝置）？
4. 若使用 VGA，聲音需要另一條音訊線 —— 檢查是否已接妥。

## 咪高峰

- 先檢查電源開關和電池；先換電池再去研究其他原因。
- 說話時確認接收器有訊號顯示。
- 留意兩支咪高峰使用同一頻道會造成干擾。
- 咪高峰要遠離喇叭以免回輸；若出現尖銳嘯叫聲，調低增益。

## 器材外借

::: tip 外借檢查清單
**借出：** 核實身分 → 記錄物品、資產編號、借用人、借出時間及應還時間 → 檢查
物品運作正常且配件齊全 → 明確告知歸還期限。

**歸還：** 檢查物品及全部配件已交回 → 測試能否開機 → 記錄歸還 → 為電池充電並
放回儲存位置。
:::

發現任何損壞須立即呈報，不要留給下一位借用人。
