## 儲物室

**MB402/4 —— ITSC 儲物室**，位於櫃檯區對面。

在你獨自處理之前，請要求同事示範一次外借程序。

## 器材外借系統（SUS IMS）

系統設有以下分頁：

| 分頁 | 用途 |
| --- | --- |
| Booking Listing | 以 SR／借用人／電郵／物品／條碼搜尋；可篩選 **Outstanding** 或 **Completed** |
| Booking | 開啟或編輯單一預約 |
| Loanable Item Enquiry | 查看可借用的存量 |
| Manual | 系統本身的使用手冊 |
| Logout | |

Booking Listing 右方面板顯示每項物品的 **Total** 及 **Available** 數量 —— 向
用戶承諾之前，先查看這裡。

### 預約紀錄包含

- Booking ID、借用期（from／to）
- SR 編號及部門（Department）
- 借用人（Borrower）、領取人（Collected By）、電郵
- Description —— 地點、用戶聯絡電話、額外物品、工單連結
- 物品表格：Booking Item、Book Qty、Check-Out Qty、Check-In Qty、Barcode、
  Loan Date、Loan By、Return Date、Return By

底部的操作按鈕：**Save Booking**、**Close Booking**、**Check-Out**、
**Send Summary Email**、**Exit**。

## 借出流程

1. 確認預約存在，且借用期涵蓋當天。
2. 從 MB402/4 取出物品。
3. 測試每件物品能否開機，配件是否齊全。
4. 掃描或輸入**條碼**，記錄借出數量。
5. 記錄領取人，並明確告知歸還期限。

## 歸還流程

1. 檢查所有物品及**全部配件**已交回。
2. 測試物品仍然正常運作。
3. 記錄歸還數量及歸還資料。
4. 為電池充電，並將全部物品放回儲物室。

::: warning 無線簡報器：借出與歸還都要成對
曾經有無線簡報器歸還時，其細小的 USB 接收器不見了。簡報器與接收器必須**一同**
借出及歸還 —— 每一次都要檢查接收器是否在。
:::
