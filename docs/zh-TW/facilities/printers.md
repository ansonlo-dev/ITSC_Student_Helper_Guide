# 打印機一覽

主校園每一部 **ITSC** 打印機，以及各自實際做得到甚麼：電腦室、課室及影印機房
合共 **15 部**。圖書館的打印機及共享學習空間 LYH208 那一部屬於其他部門，不在
此列 —— 那些機器出問題，是找管理它們的部門，不是找我們。

::: tip 這是參考資料，不是當值程序
打印機**當值**的做法 —— 每日四轉、卡紙、紙張與碳粉 —— 請看
[打印機檢查](/zh-TW/duties/printing)。這一頁是它背後的資料：哪一部有彩色、
IP 位址是甚麼，以及同學問「可唔可以用自己部電腦打印」時應該怎樣答。
:::

## 打印收費

全校**所有收費打印機劃一收費**，在機上用八達通付款：

| | 單面 | 雙面 |
| --- | --- | --- |
| **黑白 A4** | HK$0.3 | HK$0.4 |
| **黑白 A3** | HK$0.6 | HK$0.8 |
| **彩色 A4** | HK$2.5 | HK$3.5 |
| **彩色 A3** | HK$5.0 | HK$7.0 |

例外是 **ITSC 電腦室及課室的 HP 打印機**：這些是**免費**的，但要用家**自備
紙張**，而且只能**黑白、A4**。

::: warning 只收實體八達通卡
讀卡器**不支援 NFC**。手機或手錶上的八達通無論怎樣拍都不會有反應，一定要用
實體卡。
:::

## 用自己的裝置打印

以下全部都要連**校園網絡** —— 校園 Wi-Fi，或在校外經 LUVPN。

### RICOH 每份工作都要設列印密碼

**所有 RICOH 打印機都會扣住列印工作，直到在機上輸入列印密碼為止。**如果送出
工作時沒有設密碼，打印機的清單裡根本不會出現這份工作，用家就會站在機前以為
甚麼都沒送到。

- 在**學校的 Windows 電腦**上，打印機設定視窗內可能有設定列印密碼的選項。
- 如果沒有，就**先轉存成 PDF，再列印那個 PDF** —— 這條路一定會彈出密碼提示。

### 用打印機自己的網頁上載 PDF

任何有瀏覽器的裝置都做得到，所以這是同學拿著手機時最容易教的一招。

1. 用瀏覽器開該打印機的 **IP 位址**。
2. 在左邊選單按 **Print**。
3. 上載 PDF。

清單中標示為**打印機網頁（上載 PDF）**。已確認可行的是 **LBY303、LCH201、
LCH204、LCH206 及 LCH209** 的 HP 打印機。

### 用手機的 RICOH Smart Device Connector

RICOH 影印機方面，在手機裝 **RICOH Smart Device Connector**，用**主機名稱**
加入該打印機，再從 App 列印 PDF。Android 與 iOS 都可以。

### 在自己的電腦上手動加入佇列

每一張卡都附有實際試通了的位址與驅動程式：HP 機是
`socket://10.2.124.11:9100` 配 *HP LaserJet P3010 Series Postscript*，影印機
則是 `lpd://203.188.127.234` 配 *Ricoh IM 7000 PDF*。這些是在
**Ubuntu 24.04** 上測試的；任何支援以 URI 新增打印機的系統都可用同一位址。

Windows 與 macOS 那兩欄，來源試算表填的是 **「?」**而不是剔號 —— 理論上裝好
該型號的驅動程式就可以，但未有人實際確認過。跟用家講清楚是「應該可以」，不要
講到十拿九穩。

## 容易出事的地方

- **較舊的 HP LaserJet P3015 可能預設沒有開雙面**。那是在打印機設定裡開的，
  不是故障。
- **有一部不能掃描至郵件**：**SEKG02 B&W Copier 01**。我們電腦室的其餘影印機
  都可以。
- **SEKG02 與 LCH206A 的彩色影印機是新的 Ricoh C6010**，操作與其他機不同 ——
  見[新款彩色影印機](/zh-TW/duties/printing#新款彩色影印機)。
- **MB202 在 17:00 關閉**，所以較後的打印機檢查時段是進不去的。
