# 貼士總覽

「職務」告訴你要做 *什麼*；這一部分則是關於如何做得好。

- [故障排查手冊](/zh-TW/tips/troubleshooting) —— 一套可重複套用的方法，即使遇到
  從未見過的問題也能派上用場。
- [與用戶溝通](/zh-TW/tips/communication) —— 招呼、解釋、婉拒，以及應對情緒
  激動的用戶。

## 出色助理的五個習慣

1. **先重現，再修理。** 親眼看到問題；用戶的描述往往與實際發生的事有一段距離。
2. **一次只改一樣東西。** 否則你永遠不會知道是哪一步起了作用。
3. **記下你試過什麼。** 為你自己、為下一更，也為用戶。
4. **設定時限。** 若花了 15 分鐘仍毫無進展，就升級處理。
5. **收尾要完整。** 告訴用戶發生了什麼事，以及若問題再現該怎麼辦。
