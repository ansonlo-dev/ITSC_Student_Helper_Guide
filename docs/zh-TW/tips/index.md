# 貼士總覽

職務頁面告訴你要做*什麼*；這一部分則是關於如何做得好。

- [故障排查手冊](/zh-TW/tips/troubleshooting) —— 課室設備的標準檢查步驟，以及
  何時應該停手升級。
- [與用戶溝通](/zh-TW/tips/communication) —— 四項櫃檯貼士，以及應對趕時間或
  情緒激動的用戶。

## 出色助理的五個習慣

1. **只預訂自己確實能出席的更份。** 學業優先 —— 要放棄更份就早放，不要拖到最後。
2. **每次都跟足五個步驟。** 訂更、簽到、執行職務、提交結果、簽退。漏做任何一步，
   系統都會攔截。
3. **先問當值職員。** 亂猜所花的時間，遠比開口問要多得多。
4. **記錄下來。** 每宗查詢都要填表；每個故障都要記錄在檢查表上，連同房號及
   機器名稱。
5. **物歸原處。** 鎖匙、工作證、椅子、器材、電池。
