# 故障排查手冊

## 課室設備：標準檢查步驟

接到課室設備問題 —— 尤其是關於**投影機或顯示面板** —— 應先**在電話上與用戶
一同**完成以下基本檢查，然後才開工單或要求即時支援：

::: tip 四項基本檢查
1. **在觸控面板上開啟影音系統**，並選擇訊號源，例如 Desktop 或 Notebook。
2. **開啟電腦、開啟螢幕、登入電腦。**
3. **關閉影音系統及電腦電源，然後重新啟動。**
4. **檢查電腦的顯示模式**，按 `Windows` + `P` —— 通常選擇 **「Extend」
   （延伸）**。
:::

大部分課室求助都能靠這四步其中之一解決。升級處理之前，請按次序逐項嘗試。

![Windows 投影選單](/images/windows-project-menu.jpg)
*`Windows` + `P` —— 選 **Extend***

## 你實際會遇到的故障

來自各項檢查職務，大致按出現頻率排列：

| 故障 | 處理 |
| --- | --- |
| 投影模式未設為 Duplicate／Extend | `Windows`+`P` → **Extend** |
| 電源插頭被拔出 | 檢查座位下方的電源排插 —— [詳細步驟](#電腦無法開機) |
| 螢幕線鬆脫 | 兩端重新插實 |
| 觸控面板被靜音或音量調到最低 | 解除靜音，在面板調高音量 |
| 鏡頭畫面全黑 | **鏡頭蓋**未打開，或鏡頭被撥開 |
| 電腦無法登入 | 通常是沒有網絡 —— [要解決](#沒有網絡-或者電腦登入不到)，不是記錄低就算 |
| 喇叭沒有聲音 | 檢查 Windows 的**輸出裝置**、接線及 **Extron 面板** —— [詳細步驟](#沒有聲音-——-檢查輸出裝置-不只是音量) |
| 黃色標籤缺失 | 被學生撕走，要呈報 |

## 三個你可以即場搞掂的故障

「壞咗」的求助，大部分都是這三個，而且全部都不需要開工單。次序要依足：
**先電源、再網絡、後聲音** —— 部機沒有電，其他一切都測試不到。

### 電腦無法開機

十次有九次是插頭被拔出 —— 清潔姐姐、學生充電、或者枱底被腳踢到。

1. **先看有沒有任何燈亮著**：主機、螢幕，以及電源排插自己的開關。全部漆黑通常
   即是完全沒有電；主機著燈但螢幕黑，那是**螢幕或線材**的問題，不是電源問題。
2. **沿電源線找到枱底的電源排插。** **兩端**都要檢查 —— 排插上的插座，以及主機
   背後的插口，逐個推到底插實。
3. **檢查電源排插本身** —— 開關是否已開，它自己的插頭是否仍在牆插上。一個鬆脫
   的排插，可以同時令主機、螢幕、甚至隔離枱都沒有電。
4. **螢幕有自己的插頭。** 開得機但一片黑屏，往往只是螢幕沒插電或沒開掣。
5. **換排插上另一個插座試。** 若只有某一個插座不行，就是該插座壞了 —— 記錄低。

全部插實之後仍然完全沒有反應，就停手，按 `Machine Name - Cannot Power On` 呈報。
**不要拆機。**

### 沒有網絡，或者電腦登入不到

登入要用校園網絡，所以**「登入不到」和「上不到網」通常是同一個故障** ——
網絡線被拔出。

1. **看工作列右下角的網絡圖示。** 出現地球或紅色交叉，即是沒有連線。
2. **檢查 RJ45 網絡線兩端** —— 主機背後的網絡插口，以及牆身或地台的插座。要推到
   **「咔」一聲**。塑膠卡扣斷了的話，條線會滑出一半，看上去插著其實沒有接通。
3. **看主機網絡插口旁邊的小燈。** 完全不亮，問題就在線材、插座或另一端。
4. **插實之後重新啟動電腦** —— 開機時找不到網絡的機器，未必會自己重新連上。

::: warning 呈報線材之前，先確認範圍
如果房內**每一部**機都上不到網，那就不是線材問題，而是網絡或服務中斷。應立即
升級處理，不要逐張枱去重插線。
:::

單獨一部機做完以上所有步驟仍然上不到網，按 `Machine Name - Cannot Login` 呈報。

### 沒有聲音 —— 檢查輸出裝置，不只是音量

聲音有**兩重**串連的音量控制 —— Windows 和影音系統 —— 而 Windows 更可能根本把
聲音送去了另一個地方。

1. **工作列的喇叭圖示。** 解除靜音、調高音量。喇叭圖示上有交叉，出奇地經常就是
   全部問題所在。
2. **按喇叭圖示，展開輸出裝置清單。** Windows 會列出所有可以播放的裝置，而經
   HDMI 連接的投影機或顯示面板亦會是其中之一。若選中了投影機，聲音就會走去投影機
   而不是房間的喇叭 —— 要改選**房間喇叭／Extron 輸出**。
3. **檢查個別程式。** 在喇叭圖示上按右鍵 → **音量混音器（Volume mixer）** ——
   系統音量正常，但瀏覽器分頁或播放器自己被靜音，是常見情況。
4. **然後才是影音那一邊** —— 觸控面板的音量與靜音，以及 **Extron 面板**，兩者都
   要開著。
5. **用一段短 YouTube 片重測**，十秒已經足夠，要真的聽到喇叭出聲，不是假設它出聲。

**除了 AV 訊號源，電腦本身亦要測試** —— 一邊有聲一邊沒有，就能把故障收窄到那條
路徑上，而這個細節應該寫入你的呈報。

## 用 Zoom 測試鏡頭

要用 **Zoom**，不要用 Windows Camera App —— 內置程式在切換鏡頭時會 freeze，而
**LKKG0X** 根本無法在那裏更改鏡頭設定。你**不需要**登入 Zoom；未登入一樣可以
開設定。

**1. 在系統匣（system tray）找出 Zoom。** 按工作列右邊的箭嘴展開隱藏圖示，Zoom
是藍色的 **zm** 圖示 —— 把滑鼠移上去會顯示「Zoom - not signed in」，這是正常的。

![隱藏圖示中的 Zoom 圖示](/images/zoom-tray-icon.jpg)
*未登入也沒問題 —— 一樣可以開設定*

**2. 在 Zoom 圖示上按右鍵，選 Settings…** 要按右鍵，不是左鍵；按左鍵只會開啟
Zoom 視窗。

![Zoom 系統匣選單，Settings 在 Sign in 下方](/images/zoom-tray-menu.jpg)
*Screenshot、Join meeting、Share screen、Sign in，然後就是 **Settings…***

**3. 開啟 Video 分頁。** 上方的預覽畫面就是鏡頭現在看到的東西。預覽全黑，九成
是**鏡頭蓋未打開**或鏡頭被撥開 —— 呈報之前先檢查這一點。

![Zoom 設定的 Video 分頁，顯示鏡頭預覽](/images/zoom-settings-video.jpg)
*預覽顯示目前的鏡頭；Camera 下拉選單就在下面*

**4. 在 Camera 下拉選單切換鏡頭。** 有兩個鏡頭的房間，兩個都會列在這裏 —— 逐個
選一次，分別測試 **Facing Teacher** 及 **Facing Students**。如果應該有的鏡頭沒
有出現在清單上，這本身就是故障，要呈報。

![Camera 下拉選單顯示已連接的鏡頭](/images/zoom-camera-dropdown.jpg)
*只有一項，即是只連接了一個鏡頭*

::: tip 順手一併檢查
實體支架也要看 —— 腳架鬆動，或鏡頭是用膠紙臨時固定的，即使畫面正常也算故障。
:::

## 升級處理之前

按這個次序詢問用戶：

- 你原本想做什麼？
- 結果實際發生了什麼？（請對方一字不漏地說出錯誤訊息。）
- 上一次正常運作是什麼時候？
- 之後有什麼改變？
- 是每次都出現，還是只是偶爾出現？

然後界定影響範圍 —— 是**這一位用戶**、**這一部機器**，還是**所有人**？

| 範圍 | 可能成因 | 行動 |
| --- | --- | --- |
| 一位用戶，任何機器 | 帳戶、權限 | 引導至自助頁面，再交當值職員 |
| 一部機器，任何用戶 | 硬件、本機設定、線材 | 檢查機器 |
| 所有人 | 網絡或服務中斷 | 立即升級處理 |

整間房、整棟大樓的故障，絕對不應逐部機器去排查 —— 應直接呈報。

## 值得先檢查的簡單事項

1. 有沒有開機、有沒有插電 —— **兩端**都要檢查？
2. 是否用對了裝置、對的插口、對的輸入訊號源？
3. Caps Lock、鍵盤語言、用戶名打錯字
4. 是否連上了正確的網絡？
5. 問題出現之後有沒有重新啟動過？

## 何時應該停手

::: warning 與其亂猜，不如發問
任何不確定的事情，都應該詢問全職職員。**先找當值職員，然後才找其他人。**
:::

遇到以下情況，不需排查，立即升級：

- 整個電腦室、整間房、整棟大樓或整項服務中斷
- 帳戶權限、保安，或懷疑帳戶被入侵
- 可能有資料遺失
- 用戶動怒或想要作出投訴

各類問題的專責聯絡人見[聯絡與升級處理](/zh-TW/reference/contacts)。
