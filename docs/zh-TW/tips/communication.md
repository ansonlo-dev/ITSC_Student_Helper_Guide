# 與用戶溝通

## 四項櫃檯貼士

::: tip 迎新簡介的重點
1. **仔細聆聽**對方的問題，理解他們的**真實情況**。
2. 留意自己說話的**速度與語氣**。
3. 評估事情的**緊急程度**。
4. 向 ITSC 同事求助時，先講清楚該查詢是**親臨還是電話**。
:::

第 4 點比表面看來重要得多。同事會為站在櫃檯前的人立即放下手上工作，但對電話
查詢的處理方式並不相同 —— 所以描述問題之前，先說明是哪一種。

## 聽出真正的問題

用戶描述的是他們留意到的徵狀，而不是他們真正遇到的問題。「打印機壞了」可能是
卡紙、缺紙、房間關閉，也可能是把工作送去了錯的打印機。接受對方的判斷之前，
先問清楚他原本想做什麼。

## 語速與語氣

- 放慢速度。你熟悉這些系統，他們並不熟悉。
- 配合用戶的語言 —— 英文、廣東話或普通話 —— 若察覺對方用另一種語言更自在，
  就轉過去。
- 避免術語。說出用戶**需要做什麼**，而不是解釋系統在做什麼。
- 沉默會令人不安。大約每分鐘簡短說一句進展就足夠。

## 評估緊急程度

有一班學生在課室等候，優先於櫃檯的一般查詢。詢問是否正在阻礙一節課堂或一個
死線，並據此安排先後。

## 婉拒要求

你經常需要說「不」—— 尤其帳戶操作並不在你的職權範圍。要說得清楚，並提供
下一步：

> 「這件事超出了我可以處理的範圍，不過我現在就請當值職員過來幫你。」

> 「我不能在這裡幫你重設密碼，但這個自助頁面可以做到 —— 我陪你一步步做。」

不要不斷道歉、不要臨時編造理由，也不要怪責同事或「系統」。說明界限，然後給出
可行的下一步。

## 用戶情緒激動時

1. 讓對方說完。不要打斷，也不要急於辯解。
2. 認同對方受到的影響。
3. 複述一次問題，讓對方知道你有聽進去。
4. 說出你現在*可以*做什麼，並明確交代時間。
5. 若對方仍然憤怒或想投訴，請全職職員過來。這是正確做法，不是最後手段。

切勿與用戶爭辯、切勿提高聲量，也不要把事情視為針對自己。若感到不安全，請離開
現場並致電[校園保安](/zh-TW/reference/contacts)。

## 收尾

表格記錄該宗查詢，包括其狀態。若你答應過回電，就必須做到 —— 由你本人，或由
接手的同事完成。
