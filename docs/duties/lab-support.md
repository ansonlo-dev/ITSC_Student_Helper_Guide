## XClass

Labs where you would otherwise log in to more than 20 machines have **XClass**
installed — check a whole lab at once. From the teacher PC you can:

- Control every student PC centrally
- Select some or all machines and power them **on or off with one click**
- See a monitoring view of which screens are on

**Login details:**

| Field | Value |
| --- | --- |
| Log on name | Your own username |
| Password | Your own password |
| Domain | `Lingnan Daxue` |

::: info Rooms with XClass installed
LBY301, LBY303, LCH201, LCH202, LCH206, LCH209, MB202, SEKG03, SEK105.
:::

Administrators can see which machine each student logged in and out from — not
what was done on it.

::: tip Verify the numbering
Check that the XClass tile numbers match the physical PC numbers — the positions
have been found mixed up before. Where XClass is not installed, work through the
machines one by one; `Alt`+`F4` then `Enter` is the fastest way to shut each one
down.
:::

### Table glass partition

In labs that have them, check the **desktop glass partition** as well. Students
report missing labels or monitors that will not switch on — **photograph these**
and attach the photo.

### Work evidence

The photo upload field is **optional** on this form (it is mandatory on Morning
Check), but use it whenever you report a fault — a photo settles what "not ok"
actually looked like.

## Camera checks

Two methods:

1. **Zoom** — log in, **Settings → Video**; you can see both the C930 and C925
   cameras. Paul has posted a demo video in the group.
2. **The built-in Windows Camera app.**

::: warning SCK 103/104 — Zoom only
You cannot change the camera setting in the system Camera app in SCK 103/104.
Use Zoom for those rooms.
:::

The most common false report is a camera that looks black because someone left
the **lens cover closed** or turned it away. Check the cover before reporting.

## Common faults

- Projection mode not set to **Duplicate / Extend**
- Power plug pulled out
- Monitor cable loose
- Touch panel volume muted or turned right down
- Webcam case cover left closed

## Before you leave

::: tip End-of-check routine
1. **Shut down every PC** you checked — use XClass where installed, otherwise
   `Alt`+`F4`, `Enter`, one by one.
2. **Shut down the projector and visualizer.**
3. **Turn off the control panel.**
4. **Leave one light on.**
:::
