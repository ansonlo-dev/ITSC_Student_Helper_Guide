# Hostel Clinic Check

**Every Monday and Thursday, 19:00 – 22:00**, in **Hostel B, Hostel H and
Hostel WJY**. One helper per hostel.

The duty is hostel network checking — confirming students can get onto the
campus wireless network from the hostels.

## Submit the result twice

::: warning Two submissions per shift
Submit the checking result at **8:30 pm** and again at **10:00 pm** — two times,
not one.
:::

The 8:30 pm submission is the main test; the form itself notes "The test shall be
carried out at 8:30pm".

## The form

Open **→ Hostel Clinic Check ←** from the checklist links page and submit the
**Hostel Clinic Checklist**:

| Field | Notes |
| --- | --- |
| Name of Helper | |
| Date and Time | |
| Location | Which hostel and where in it |
| WiFi Connection (LU) | **Connect successfully** / **Cannot Connect successfully** |

## Signing in for this duty

At [ics.ln.edu.hk/helper](https://ics.ln.edu.hk/helper), choose
**Helper Sign in/out → Hostel Clinic Helper** (not User Service Helper). Your
records for this duty appear with type **HC**.

## If the network is down

Record it honestly on the form, then report it. Network problems go to
**Max Yiu, 2616-8412** — see [Contacts & Escalation](/reference/contacts).
