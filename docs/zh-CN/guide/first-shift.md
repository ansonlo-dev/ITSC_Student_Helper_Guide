# 第一次值班值班

## 出发前

- 在值班表上确认你的值班时间及地点。
- 清楚知道当班的主管是谁。
- 带备学生证 —— 进入大楼或房间时可能需要。
- 衣着整洁。你是许多用户接触 ITSC 的第一个人。

## 抵达时

::: tip 开班检查清单
1. 在值班纪录上签到。
2. 阅读上一班留下的交接笔记。
3. 检查服务柜台／电脑室有没有未修复或未处理的问题。
4. 登入当班需要用到的系统。
5. 询问上一班的同事有没有未完成的事项。
:::

## 值班期间

- 主动招呼每一位前来的用户。即使只说一句“请稍等一两分钟”，也胜过沉默。
- 记录你处理过的每一个工单 —— 详见[服务柜台](/zh-CN/duties/service-counter)。
- 若无法在合理时间内解决问题，应升级处理，不要让用户一直等。

## 收班时

::: tip 收班检查清单
1. 完成或交接所有仍在处理中的事项。
2. 为下一班撰写交接笔记 —— 未解决的工单要写得具体。
3. 整理柜台／电脑室：椅子、线材，外借器材归位。
4. 登出所有共享账户并锁上工作站。
5. 在值班纪录上签退。
:::

## 无法值班时

尽早通知主管，并依照团队的换班程序处理。切勿在未通知职员的情况下，私下自行安排
他人代班。
