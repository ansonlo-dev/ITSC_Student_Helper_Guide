# 工作注意事项

## 学业优先

**学业优先。享受你的大学生活。**

这份工作是围绕你的学业而设，而不是相反。只预订自己确实能够出席的班次；当学业
需要时间时，请及早放弃班次。

## 团队期望

::: tip 团队对你的要求
**诚实 · 自律 · 责任感 · 时间管理 · 沟通能力 · 互相尊重**
:::

学业永远优先 —— 但在值班期间，ITSC 学生助理应以最高标准展现以上每一项。请好好
安排自己的时间表与课业，让你仍然可以尽情享受大学生活。

## 这个计划的意义

::: tip 不只是为了赚钱
正如 Paul 所说，学生助理计划的设计，并不只是为了赚钱，而是一个提升**沟通能力**、
**解难能力**及**就业准备**的机会。保持自律、尊重同伴 —— 最重要的是，好好享受
你的大学生活。
:::

## 应做与不应做

| 应做（Do） | 不应做（Don't） |
| --- | --- |
| **诚实**（Honest） | **接更或请假而不发信息** |
| **准时**（Punctual） | **无故缺席** |
| **乐于助人**（Helpful） | **太迟才发请假信息** |
| **有礼**（Polite） | **未做检查就提交报告** |
| **每日至少查看一次 WhatsApp 群组** | **迟签到或早签退** |

::: danger 绝不提交没有做过的报告
未做检查就提交检查结果，是唯一一件会摧毁整个制度价值的事 —— 那份报告是 ITSC
唯一能够得知房间是否准备妥当的信号。
:::

即使只是提早 15 分钟签退，也会被视为违规，而非“差不多”。

## 工作证明（Work Evidence）

各项检查职务都要求上传**相片**作为工作证明。

| 职务 | 相片栏位 |
| --- | --- |
| 早上检查 | **必填** |
| 教室检查 | 有此栏（Work-Evidence，第 26 题） |
| 电脑室检查 | 选填 |
| 打印机检查 | 选填 |

::: warning 怎样才算有效的相片
必须显示**时间**及**现场环境** —— 不能只是自拍。建议做法：拍下开着的镜头、
自己，以及房间的状况。
:::

此要求是在有助理签到后离开去吃早餐之后才引入的。ITSC 本来就能查阅登入纪录；
相片只是作为简单的实际证明，表格其余部分仍然建基于信任。

## 佩戴工作证

::: danger 服饰及身份识别是强制要求
学生助理**值班期间必须全程佩戴**工作证。
:::

工作证有三个作用：

1. 建立**专业形象**。
2. 让职员及你正在协助的同学**认得你的身份**。
3. 在**非办公时间要求开启房间**时，让保安员辨认你的身份。

## 请假

若无法出席已预订的班次：

1. **在 WhatsApp 群组发信息**，格式如下：

   ```
   Leave
   Name: Homan
   Date: 15/1/2025
   Time: 10:30-12:30
   Duty: printer check
   Reason: sickness
   ```

2. **自行从 [helperduty.top](https://helperduty.top) 移除你的班次纪录。**

两个步骤缺一不可 —— 只发信息并不会释放该班次。而且要尽早发出；太迟的请假信息
造成的困扰，与不发信息相差无几。

![WhatsApp 群组中的请假信息](/images/whatsapp-leave.jpg)

2. **在 [helperduty.top](https://helperduty.top) 预订该班次纪录。**

## 柜台整洁

所有物品都必须放回原位，保持整齐清洁。

- 坐过的椅子要推回原位。
- 工作证放回抽屉柜。
- 柜台工作站及电话保持你到达时的状态。

![柜台的工作证抽屉](/images/badge-drawer.jpg)
*工作证要放回抽屉柜，不要带走*

## 检查完离开房间之前

- **关闭所有你检查过的电脑。**
- **关闭投影仪及实物投影仪**，并关掉控制面板。
- **留一盏灯开着。**

## 归还钥匙及物资

- **Ricoh 打印机钥匙**必须归还到你取用的位置，并重新锁好打印机。
- 值班袋及其内容物（工作证、麦克风、麦克风套、音讯 CD、电池）须放回 LCH206A 或
  MB202。
- 外借器材必须连同所有配件送回储藏室。
