# 工作注意事项

## 学业优先

**学业优先。享受你的大学生活。**

这份工作是围绕你的学业而设，而不是相反。只预订自己确实能够出席的班次；当学业
需要时间时，请及早放弃班次。

## 五项要求

::: tip 团队对你的期望
- **诚实（Honesty）**
- **自律（Self-discipline）**
- **责任感（Responsibility）**
- **时间管理（Time management）**
- **互相尊重（Respect each other）**
:::

## 佩戴工作证

值班期间必须佩戴 ITSC Student Helper 工作证。用户需要知道你的身份，职员亦需要
知道你有权出现在该处。

## 请假

若无法出席已预订的班次：

1. **在 WhatsApp 群组发信息**，格式如下：

   ```
   Leave
   Name: Homan
   Date: 15/1/2025
   Time: 10:30-12:30
   Duty: printer check
   Reason: sickness
   ```

2. **自行从 [luhelperduty.online](https://luhelperduty.online) 移除你的班次纪录。**

两个步骤缺一不可 —— 只发信息并不会释放该班次。

## 接手他人的班次

当其他助理发出请假信息而你可以接手时：

1. **在 WhatsApp 群组回复**（例如“i can take”）。
2. **在 [luhelperduty.online](https://luhelperduty.online) 预订该班次纪录。**

## 柜台整洁

所有物品都必须放回原位，保持整齐清洁。

- 坐过的椅子要推回原位。
- 工作证放回抽屉柜。
- 柜台工作站及电话保持你到达时的状态。

## 归还钥匙及物资

- **Ricoh 打印机钥匙**必须归还到你取用的位置。
- 值班袋及其内容物（工作证、麦克风、麦克风套、音讯 CD、电池）须放回 LCH206A 或
  MB202。
- 外借器材必须连同所有配件送回储藏室。
