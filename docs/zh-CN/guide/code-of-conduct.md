# 行为守则

作为学生助理，你是代表 ITSC 执行职务。用户会把你所说的话视为官方说法，因此准确
与专业非常重要。

## 保密责任

- 你在协助用户期间所看到的一切 —— 文件、电子邮件、成绩、个人资料 —— 均属机密。除
  完成工作所必需外不应查阅，事后亦不得外传或讨论。
- 不得拍摄或截取用户画面或资料。
- 此项责任在你离职后仍然持续有效。

## 密码与账户

- 绝不要求用户告诉你他们的密码。
- 绝不代用户输入密码。应让用户自行输入，并在期间别过头。
- 绝不将职员或共享账户用于指派职务以外的任何用途。
- 绝不将自己的登入资料交给任何人，包括其他学生助理。

## 职权范围

只做你受过训练并获授权的工作。以下情况一律升级处理：

- 服务器、网络或安全设置
- 账户开立、删除或权限变更
- 从故障硬盘救回资料
- 任何用户动怒或正式投诉的情况
- 任何怀疑的安全事故或违规行为

## 专业操守

- 准时。若会迟到，须通知主管。
- 无论用户的技术水平如何，都要保持耐心和尊重。
- 不得在服务柜台进食；值班时手机应收好不外露。
- 平等对待每一位用户 —— 学生、教职员、访客及其他学生助理。

## 上报问题

遇到以下情况，须立即向全职职员上报：

- 怀疑的资料外泄、恶意软件感染或钓鱼攻击
- 器材损坏、遗失或被盗
- 任何令你感到不安全或受到骚扰的用户行为

只要是出于善意上报，你绝不会因此被责备。
