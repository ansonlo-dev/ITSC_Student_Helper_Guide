# 故障排查手册

## 教室设备：标准检查步骤

接到教室设备问题 —— 尤其是关于**投影仪或显示面板** —— 应先**在电话上与用户
一同**完成以下基本检查，然后才开工单或要求即时支援：

::: tip 四项基本检查
1. **在触控面板上开启视听系统**，并选择信号源，例如 Desktop 或 Notebook。
2. **开启电脑、开启显示器、登入电脑。**
3. **关闭视听系统及电脑电源，然后重新启动。**
4. **检查电脑的显示模式**，按 `Windows` + `P` —— 通常选择 **“Extend”
   （延伸）**。
:::

大部分教室求助都能靠这四步其中之一解决。升级处理之前，请按顺序逐项尝试。

![Windows 投影选单](/images/windows-project-menu.jpg)
*`Windows` + `P` —— 选 **Extend***

## 你实际会遇到的故障

来自各项检查职务，大致按出现频率排列：

| 故障 | 处理 |
| --- | --- |
| 投影模式未设为 Duplicate／Extend | `Windows`+`P` → **Extend** |
| 电源插头被拔出 | 检查座位下方的电源排插 —— [详细步骤](#电脑无法开机) |
| 显示器线松脱 | 两端重新插实 |
| 触控面板被静音或音量调到最低 | 解除静音，在面板调高音量 |
| 镜头画面全黑 | **镜头盖**未打开，或镜头被拨开 |
| 电脑无法登入 | 通常是没有网络 —— [要解决](#没有网络-或者电脑登入不了)，不是记录低就算 |
| 扬声器没有声音 | 检查 Windows 的**输出设备**、接线及 **Extron 面板** —— [详细步骤](#没有声音-——-检查输出设备-不只是音量) |
| 黄色标签缺失 | 被学生撕走，要上报 |

## 三个你可以当场解决的故障

「坏了」的求助，大部分都是这三个，而且全部都不需要开工单。次序要依足：
**先电源、再网络、后声音** —— 机器没有电，其他一切都测试不了。

### 电脑无法开机

十次有九次是插头被拔出 —— 清洁人员、学生充电、或者桌底被脚踢到。

1. **先看有没有任何灯亮着**：主机、显示器，以及电源排插自己的开关。全部漆黑通常
   即是完全没有电；主机亮灯但屏幕黑，那是**显示器或线材**的问题，不是电源问题。
2. **沿电源线找到桌底的电源排插。** **两端**都要检查 —— 排插上的插座，以及主机
   背后的插口，逐个推到底插实。
3. **检查电源排插本身** —— 开关是否已开，它自己的插头是否仍在墙插上。一个松脱
   的排插，可以同时令主机、显示器、甚至邻桌都没有电。
4. **显示器有自己的插头。** 开得了机但一片黑屏，往往只是显示器没插电或没开关。
5. **换排插上另一个插座试。** 若只有某一个插座不行，就是该插座坏了 —— 记录下来。

全部插实之后仍然完全没有反应，就停手，按 `Machine Name - Cannot Power On` 上报。
**不要拆机。**

### 没有网络，或者电脑登入不了

登入要用校园网络，所以**「登入不了」和「上不了网」通常是同一个故障** ——
网线被拔出。

1. **看任务栏右下角的网络图标。** 出现地球或红色交叉，即是没有连线。
2. **检查 RJ45 网线两端** —— 主机背后的网络插口，以及墙身或地台的插座。要推到
   **「咔」一声**。塑料卡扣断了的话，线会滑出一半，看上去插着其实没有接通。
3. **看主机网络插口旁边的小灯。** 完全不亮，问题就在线材、插座或另一端。
4. **插实之后重新启动电脑** —— 开机时找不到网络的机器，未必会自己重新连上。

::: warning 上报线材之前，先确认范围
如果房内**每一台**机器都上不了网，那就不是线材问题，而是网络或服务中断。应立即
升级处理，不要逐张桌子去重插线。
:::

单独一台机器做完以上所有步骤仍然上不了网，按 `Machine Name - Cannot Login` 上报。

### 没有声音 —— 检查输出设备，不只是音量

声音有**两重**串连的音量控制 —— Windows 和影音系统 —— 而 Windows 更可能根本把
声音送去了另一个地方。

1. **任务栏的扬声器图标。** 解除静音、调高音量。扬声器图标上有交叉，出奇地经常
   就是全部问题所在。
2. **点击扬声器图标，展开输出设备列表。** Windows 会列出所有可以播放的设备，而经
   HDMI 连接的投影机或显示面板亦会是其中之一。若选中了投影机，声音就会走去投影机
   而不是房间的扬声器 —— 要改选**房间扬声器／Extron 输出**。
3. **检查个别程序。** 在扬声器图标上点右键 → **音量合成器（Volume mixer）** ——
   系统音量正常，但浏览器标签页或播放器自己被静音，是常见情况。
4. **然后才是影音那一边** —— 触控面板的音量与静音，以及 **Extron 面板**，两者都
   要开着。
5. **用一段短 YouTube 片重测**，十秒已经足够，要真的听到扬声器出声，不是假设它
   出声。

**除了 AV 信号源，电脑本身亦要测试** —— 一边有声一边没有，就能把故障收窄到那条
路径上，而这个细节应该写入你的上报。

## 用 Zoom 测试镜头

要用 **Zoom**，不要用 Windows Camera App —— 内置程序在切换镜头时会 freeze，而
**LKKG0X** 根本无法在那里更改镜头设置。你**不需要**登入 Zoom；未登入一样可以
开设置。

**1. 在系统匣（system tray）找出 Zoom。** 按任务栏右边的箭头展开隐藏图示，Zoom
是蓝色的 **zm** 图示 —— 把鼠标移上去会显示“Zoom - not signed in”，这是正常的。

![隐藏图示中的 Zoom 图示](/images/zoom-tray-icon.jpg)
*未登入也没问题 —— 一样可以打开设置*

**2. 在 Zoom 图示上按右键，选 Settings…** 要按右键，不是左键；按左键只会开启
Zoom 窗口。

![Zoom 系统匣选单，Settings 在 Sign in 下方](/images/zoom-tray-menu.jpg)
*Screenshot、Join meeting、Share screen、Sign in，然后就是 **Settings…***

**3. 开启 Video 分页。** 上方的预览画面就是镜头现在看到的东西。预览全黑，九成
是**镜头盖未打开**或镜头被拨开 —— 上报之前先检查这一点。

![Zoom 设置的 Video 分页，显示镜头预览](/images/zoom-settings-video.jpg)
*预览显示目前的镜头；Camera 下拉选单就在下面*

**4. 在 Camera 下拉选单切换镜头。** 有两个镜头的房间，两个都会列在这里 —— 逐个
选一次，分别测试 **Facing Teacher** 及 **Facing Students**。如果应该有的镜头没
有出现在清单上，这本身就是故障，要上报。

![Camera 下拉选单显示已连接的镜头](/images/zoom-camera-dropdown.jpg)
*只有一项，即是只连接了一个镜头*

::: tip 顺手一并检查
实体支架也要看 —— 脚架松动，或镜头是用胶纸临时固定的，即使画面正常也算故障。
:::

## 升级处理之前

按这个顺序询问用户：

- 你原本想做什么？
- 结果实际发生了什么？（请对方一字不漏地说出错误信息。）
- 上一次正常运行是什么时候？
- 之后有什么改变？
- 是每次都出现，还是只是偶尔出现？

然后界定影响范围 —— 是**这一位用户**、**这一台机器**，还是**所有人**？

| 范围 | 可能成因 | 行动 |
| --- | --- | --- |
| 一位用户，任何机器 | 账户、权限 | 引导至自助页面，再交值班职员 |
| 一台机器，任何用户 | 硬件、本机设置、线材 | 检查机器 |
| 所有人 | 网络或服务中断 | 立即升级处理 |

整间房、整栋大楼的故障，绝对不应逐台机器去排查 —— 应直接上报。

## 值得先检查的简单事项

1. 有没有开机、有没有插电 —— **两端**都要检查？
2. 是否用对了设备、对的接口、对的输入信号源？
3. Caps Lock、键盘语言、用户名打错字
4. 是否连上了正确的网络？
5. 问题出现之后有没有重新启动过？

## 何时应该停手

::: warning 与其乱猜，不如发问
任何不确定的事情，都应该询问全职职员。**先找值班职员，然后才找其他人。**
:::

遇到以下情况，不需排查，立即升级：

- 整个电脑室、整间房、整栋大楼或整项服务中断
- 账户权限、安全，或怀疑账户被入侵
- 可能有资料遗失
- 用户动怒或想要作出投诉

各类问题的专责联系人见[联系与升级处理](/zh-CN/reference/contacts)。
