# 提示总览

“职务”告诉你要做 *什么*；这一台分则是关于如何做得好。

- [故障排查手册](/zh-CN/tips/troubleshooting) —— 一套可重复套用的方法，即使遇到
  从未见过的问题也能派上用场。
- [与用户沟通](/zh-CN/tips/communication) —— 招呼、解释、婉拒，以及应对情绪
  激动的用户。

## 出色助理的五个习惯

1. **先重现，再修理。** 亲眼看到问题；用户的描述往往与实际发生的事有一段距离。
2. **一次只改一样东西。** 否则你永远不会知道是哪一步起了作用。
3. **记下你试过什么。** 为你自己、为下一班，也为用户。
4. **设置时限。** 若花了 15 分钟仍毫无进展，就升级处理。
5. **收尾要完整。** 告诉用户发生了什么事，以及若问题再现该怎么办。
