# 提示总览

职务页面告诉你要做*什么*；这一台分则是关于如何做得好。

- [故障排查手册](/zh-CN/tips/troubleshooting) —— 教室设备的标准检查步骤，以及
  何时应该停手升级。
- [与用户沟通](/zh-CN/tips/communication) —— 四项柜台提示，以及应对赶时间或
  情绪激动的用户。

## 出色助理的五个习惯

1. **只预订自己确实能出席的班次。** 学业优先 —— 要放弃班次就早放，不要拖到最后。
2. **每次都跟足五个步骤。** 订班、签到、执行职务、提交结果、签退。漏做任何一步，
   系统都会拦截。
3. **先问值班职员。** 乱猜所花的时间，远比开口问要多得多。
4. **记录下来。** 每宗查询都要填表；每个故障都要记录在检查表上，连同房间号及
   机器名称。
5. **物归原处。** 钥匙、工作证、椅子、器材、电池。
