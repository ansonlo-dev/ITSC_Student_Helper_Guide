# 系统与连结

## 核心系统

| 系统 | 网址 | 用户名称 | 密码 |
| --- | --- | --- | --- |
| **班次预订系统** | [helperduty.top](https://helperduty.top) | 你的用户名称 | 你的**学号** |
| **签到／签退** | [ics.ln.edu.hk/helper](https://ics.ln.edu.hk/helper) | 你的用户名称 | 你的 **LU 密码** |

::: warning 两个系统，两个不同密码
预订系统用**学号**；签到系统用 **LU 密码**。混淆这两者是最常见的登入失败
原因。
:::

| 系统 | 可以在哪里使用 |
| --- | --- |
| **班次预订系统** | 只限校园 Wi-Fi，或校外经 **LUVPN** |
| **签到／签退** | 必须身处校园并连接校园网络 —— 宿舍助理要走到最近的课室大楼 |

::: danger 预订系统不可外传
它是一个**独立的私人数据库**，并没有与 LU 主要系统连接。**不要向大学其他部门
（例如 OSA）透露这个系统的存在。**
:::

## 没有某些设备的房间

在你标记“Not ok”之前，值得先知道：

| 房间 | 没有的设备 |
| --- | --- |
| SEK105 | 没有光碟机、没有打印机 |
| LCH413 | 没有打印机 |
| LYH308 | 没有电脑 —— 只需检查灯光和电视 |
| LKK107、LKK108、LKK110 | 没有无线麦克风，只有有线麦克风，而这是正常的 |
| MBG11 | 触控面板上没有实物投影机的选项 —— 用电脑的 Camera App |
| LKK 新翼房间 | 没有脚架（镜头固定在幕墙上） |
| LKKG0X | 无法在 Windows Camera App 更改镜头设置 —— 要用 Zoom |

## 各有不同的房间

以下每一项，都曾经被不知情的助理当成故障上报：

| 房间 | 有什么不同 |
| --- | --- |
| **MBG06** | 该房间的麦克风是**教师讲台上的数码麦克风**，**不支持**红外线麦克风 —— 红外线麦克风没有声音不是故障。 |
| **LKK 地下** | 镜头**固定在墙上**，不是桌面的小镜头。它在电脑上显示为 **「Black Magic」**，画面角度在**控制面板**上切换。 |
| **LCH206、LCH209、LCH213** | **旧款影音系统。** 实物投影机无法直接输出到投影机 —— 改为在**电脑的 Camera App** 里当成 webcam 打开。 |
| **LYH319／LYH320** | 由影音组设定为**合并模式（combined mode）** —— 一个控制面板同时服务两间房。 |
| **WYL314** | 是**会议室**；以一台笔记本电脑代替教师机。 |
| **LCH416** | 只能以 **LU 卡刷卡**进入，助理没有权限 —— 标记 **Room closed**。 |
| **LCH113** | **根本没有这间教室。** 地图上 LCH113 的位置，在 LCH 一楼其实是一间挂着「Do not enter」的科学实验室。若它出现在你的分配表上，标记 **Room closed** 并告知 Paul。 |
| **SEKG02、LCH206A 彩色复印机** | 2026 年 9 月换成需要登录的 **Ricoh C6010** —— 见[打印机检查](/zh-CN/duties/printing#新款彩色复印机)。 |
