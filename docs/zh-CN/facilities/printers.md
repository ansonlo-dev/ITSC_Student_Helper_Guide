# 打印机一览

主校园每一台 **ITSC** 打印机，以及各自实际做得到什么：电脑室、教室及复印机房
共 **15 台**。图书馆的打印机及共享学习空间 LYH208 那一台属于其他部门，不在此
列 —— 那些机器出问题，是找管理它们的部门，不是找我们。

::: tip 这是参考资料，不是值班程序
打印机**值班**的做法 —— 每天四轮、卡纸、纸张与碳粉 —— 请看
[打印机检查](/zh-CN/duties/printing)。这一页是它背后的资料：哪一台有彩色、
IP 地址是什么，以及同学问“能不能用自己的电脑打印”时应该怎么答。
:::

全校**所有收费打印机统一收费**，在机上用八达通付款：

| | 单面 | 双面 |
| --- | --- | --- |
| **黑白 A4** | HK$0.3 | HK$0.4 |
| **黑白 A3** | HK$0.6 | HK$0.8 |
| **彩色 A4** | HK$2.5 | HK$3.5 |
| **彩色 A3** | HK$5.0 | HK$7.0 |

例外是 **ITSC 电脑室及教室的 HP 打印机**：这些是**免费**的，但要用户**自备
纸张**，而且只能**黑白、A4**。

::: warning 只收实体八达通卡
读卡器**不支持 NFC**。手机或手表上的八达通无论怎么拍都不会有反应，一定要用
实体卡。
:::

## 用自己的设备打印

以下全部都要连**校园网络** —— 校园 Wi-Fi，或在校外经 LUVPN。

### RICOH 每份工作都要设打印密码

**所有 RICOH 打印机都会扣住打印工作，直到在机上输入打印密码为止。**如果送出
工作时没有设密码，打印机的清单里根本不会出现这份工作，用户就会站在机前以为
什么都没送到。

- 在**学校的 Windows 电脑**上，打印机设置窗口内可能有设置打印密码的选项。
- 如果没有，就**先转存成 PDF，再打印那个 PDF** —— 这条路一定会弹出密码提示。

### 用打印机自己的网页上传 PDF

任何有浏览器的设备都做得到，所以这是同学拿着手机时最容易教的一招。

1. 用浏览器开该打印机的 **IP 地址**。
2. 在左边菜单按 **Print**。
3. 上传 PDF。

清单中标示为**打印机网页（上传 PDF）**。已确认可行的是 **LBY303、LCH201、
LCH204、LCH206 及 LCH209** 的 HP 打印机。

### 用手机的 RICOH Smart Device Connector

RICOH 复印机方面，在手机安装 **RICOH Smart Device Connector**，用**主机名**
加入该打印机，再从 App 打印 PDF。Android 与 iOS 都可以。

### 在自己的电脑上手动加入队列

每一张卡都附有已经实际验证过的地址与驱动程序：HP 机是
`socket://10.2.124.11:9100` 配 *HP LaserJet P3010 Series Postscript*，复印机
则是 `lpd://203.188.127.234` 配 *Ricoh IM 7000 PDF*。这些是在
**Ubuntu 24.04** 上测试的；任何支持以 URI 添加打印机的系统都可用同一地址。

Windows 与 macOS 那两栏，来源电子表格填的是 **“?”**而不是勾号 —— 理论上装好
该型号的驱动程序就可以，但没有人实际确认过。跟用户讲清楚是“应该可以”，不要
讲到十拿九稳。

## 容易出事的地方

- **较旧的 HP LaserJet P3015 可能默认没有开双面**。那是在打印机设置里开的，
  不是故障。
- **有一台不能扫描至邮件**：**SEKG02 B&W Copier 01**。我们电脑室的其余复印机
  都可以。
- **SEKG02 与 LCH206A 的彩色复印机是新的 Ricoh C6010**，操作与其他机不同 ——
  见[新款彩色复印机](/zh-CN/duties/printing#新款彩色复印机)。
- **MB202 在 17:00 关闭**，所以较晚的打印机检查时段是进不去的。
