# 服务柜台

柜台是 ITSC 的门面。你遇到的用户大多已经有点不耐烦 —— 一个冷静、有条理的柜台，
在你动手碰电脑之前就已经解决了一半问题。

## 开柜台

1. 签到并阅读交接笔记。
2. 检查柜台工作站、电话及标签打印机是否正常。
3. 补充表格及外借物品。
4. 查看有没有需要向用户转达的服务公告（停机、维修时段）。

## 处理现场工单

::: tip 四条问题
1. 你原本想做什么？
2. 结果发生了什么？
3. 上一次正常运行是什么时候？
4. 你已经试过什么方法？
:::

然后：

1. **核实身份** —— 涉及账户的工单须查看学生证或职员证。
2. **分流** —— 这件事能否在柜台几分钟内解决？
3. **解决或升级** —— 不要一边让用户等，一边自己在试。
4. **记录工单**：用户报告的问题、你做过什么、最终结果。

## 应付队伍

- 有人加入队伍时要打个招呼，即使你暂时未能招呼他们。
- 在公平的前提下，可在耗时较长的工单之间穿插处理快速事项（领取物品、简单查询）。
- 若等候时间较长，坦白说出大概要等多久 —— 诚实的估算胜过沉默。
- 队伍持续变长时，召唤另一位助理或主管帮忙。

## 接听电话

- 用一致的问候语接听：部门名称、你的名字、然后提供协助。
- 在开始排查之前，先取得来电者的姓名、联系方式及回电号码。
- 复述一次问题，确认你理解无误。
- 若必须转接，要告诉来电者你会转接给谁，以及原因。

## 收柜台

1. 完成或交接未结工单。
2. 撰写交接笔记。
3. 收回外借物品，贵重物品锁好。
4. 登出共享账户；锁上工作站。
5. 签退。
