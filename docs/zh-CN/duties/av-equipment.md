## 器材外借系统（SUS IMS）

系统设有以下分页：

| 分页 | 用途 |
| --- | --- |
| Booking Listing | 以 SR／借用人／电子邮件／物品／条码搜寻；可筛选 **Outstanding** 或 **Completed** |
| Booking | 开启或编辑单一预约 |
| Loanable Item Enquiry | 查看可借用的存量 |
| Manual | 系统本身的使用手册 |
| Logout | |

Booking Listing 右方面板显示每项物品的 **Total** 及 **Available** 数量 —— 向
用户承诺之前，先查看这里。

![器材外借系统的预约清单](/images/loan-booking-listing.jpg)
*Booking Listing —— 右方显示每项物品的总数与可借数量*

### 预约纪录包含

- Booking ID、借用期（from／to）
- SR 编号及部门（Department）
- 借用人（Borrower）、领取人（Collected By）、电子邮件
- Description —— 地点、用户联系电话、额外物品、工单连结
- 物品表格：Booking Item、Book Qty、Check-Out Qty、Check-In Qty、Barcode、
  Loan Date、Loan By、Return Date、Return By

底部的操作按钮：**Save Booking**、**Close Booking**、**Check-Out**、
**Send Summary Email**、**Exit**。

![外借系统中的预约纪录](/images/loan-booking-record.jpg)
*一笔预约纪录*

## 借出流程

1. 确认预约存在，且借用期涵盖当天。
2. 从 MB402/4 取出物品。
3. 测试每件物品能否开机，配件是否齐全。
4. 扫描或输入**条码**，记录借出数量。
5. 记录领取人，并明确告知归还期限。

## 归还流程

1. 检查所有物品及**全部配件**已交回。
2. 测试物品仍然正常运行。
3. 记录归还数量及归还资料。
4. 为电池充电，并将全部物品放回储藏室。

::: warning 无线简报器：借出与归还都要成对
曾经有无线简报器归还时，其细小的 USB 接收器不见了。简报器与接收器必须**一同**
借出及归还 —— 每一次都要检查接收器是否在。

![无线简报器及其 USB 接收器](/images/wireless-presenter.jpg)
*接收器夹在简报器内 —— 每次都要确认它在*
:::
