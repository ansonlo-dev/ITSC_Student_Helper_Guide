# 影音及教室设备

影音问题几乎一律紧急：有一班学生正在等。这里比任何地方都更讲求速度和冷静的
态度。

## 回应教室求助

1. 出发前先取得房间号及确切症状。
2. 立即前往 —— 课堂正在流失时间。
3. 安静进入，向老师打招呼，动手处理而不要一路解说。
4. 若无法短时间内修好，提供替代方案（后备笔记本电脑、改用其他输入、转到附近教室），
   同时升级处理。

## 投影仪没有画面

按以下顺序逐项检查：

1. 投影仪开了吗？看灯泡／状态指示灯，不要只看投影画面。
2. 是否选对了 **输入信号源**（HDMI 1／2、VGA、无线）？
3. 线材两端是否都插实？换一条线试试。
4. 在笔记本电脑上强制侦测显示器，并设为 **复制**：
   - Windows：`Win` + `P` → 复制
   - macOS：系统设置 → 显示器 → 镜像输出
5. 用一台确认正常的笔记本电脑测试，以区分是电脑问题还是教室问题。
6. 检查该教室是否设有控制面板或矩阵切换器，需要选择正确的默认模式。

::: tip 转接头
最多投诉其实源于 USB-C／HDMI／VGA 转接头。器材车上要备有后备转接头，先检查转接头
再怪责教室设备。
:::

## 没有声音

1. 教室的音量旋钮或扩音机有否调高、是否静音？
2. 笔记本电脑音量有否调高、是否静音？
3. 笔记本电脑是否选对了 **输出设备**（HDMI、内置扬声器，还是 USB 设备）？
4. 若使用 VGA，声音需要另一条音讯线 —— 检查是否已接妥。

## 麦克风

- 先检查电源开关和电池；先换电池再去研究其他原因。
- 说话时确认接收器有信号显示。
- 留意两支麦克风使用同一频道会造成干扰。
- 麦克风要远离扬声器以免回输；若出现尖锐啸叫声，调低增益。

## 器材外借

::: tip 外借检查清单
**借出：** 核实身份 → 记录物品、资产编号、借用人、借出时间及应还时间 → 检查
物品运行正常且配件齐全 → 明确告知归还期限。

**归还：** 检查物品及全部配件已交回 → 测试能否开机 → 记录归还 → 为电池充电并
放回保存位置。
:::

发现任何损坏须立即上报，不要留给下一位借用人。
