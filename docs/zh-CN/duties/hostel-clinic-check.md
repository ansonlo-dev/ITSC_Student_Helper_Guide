# 宿舍网络检查

**每逢星期一及星期四，19:00 – 22:00**，于 **Hostel B、Hostel H 及
Hostel WJY**。每座宿舍一位助理。

此职务为宿舍网络检查 —— 确认学生能够在宿舍连接校园无线网络。

## 需要提交结果两次

::: warning 每更提交两次
检查结果须于**晚上 8:30** 及**晚上 10:00** 各提交一次 —— 是两次，不是一次。
:::

晚上 8:30 那次是主要测试；表格本身亦注明“The test shall be carried out at
8:30pm”。

## 表格内容

从检查表连结页开启 **→ Hostel Clinic Check ←**，提交
**Hostel Clinic Checklist**：

| 栏位 | 备注 |
| --- | --- |
| Name of Helper | 助理姓名 |
| Date and Time | 日期及时间 |
| Location | 哪一座宿舍、宿舍内哪个位置 |
| WiFi Connection (LU) | **Connect successfully**（成功连接）／**Cannot Connect successfully**（无法成功连接） |

## 此职务的签到方式

在 [ics.ln.edu.hk/helper](https://ics.ln.edu.hk/helper) 选择
**Helper Sign in/out → Hostel Clinic Helper**（不是 User Service Helper）。
此职务的纪录类型会显示为 **HC**。

## 若网络故障

如实记录在表格上，然后上报。网络问题请联系 **Max Yiu，2616-8412** ——
详见[联系与升级处理](/zh-CN/reference/contacts)。
