# 账户与密码

这是规则最严格的一项职务。账户存取权是 ITSC 所掌管最敏感的东西，而社交工程攻击
通常就从这里开始。

::: danger 不容妥协的底线
- **绝不**索取或接收用户的密码，无论是面对面、电话还是书面。
- **绝不**代用户输入密码。让用户自行输入，期间别过头。
- **绝不**为未按批准程序核实身份的人重置密码。
- **绝不**因为用户赶时间、职级高，或者是朋友，就“破例一次”为其重置。

若有人施压要你违反以上任何一项，这件事本身就是升级处理的理由。
:::

## 核实身份

在处理任何与账户相关的事情之前：

1. 要求出示有效的学生证或职员证。
2. 核对相片及姓名与眼前的人相符。
3. 核对姓名与将被变更的账户相符。

若为电话或电子邮件提出的要求，**不要**自行核实身份 —— 请依照批准的远程核实程序处理，
或请用户亲身前来。

## 协助用户自行重置密码

目标永远是让用户自助完成。你的角色是引导，而不是代劳：

1. 引导用户前往官方的密码重置网页。
2. 一边讲解步骤，一边让用户自己输入。
3. 在用户选择新密码之前，提醒他们密码规则。
4. 请用户在原本无法使用的服务上确认新密码有效 —— 用电子邮件或门户网站测试就很合适。
5. 提醒用户更新手机及其他设备上已保存的密码，否则反复的登入失败可能导致账户
   再次被锁定。

## 账户被锁定

账户被锁定通常是因为某处仍有设备在尝试使用旧密码 —— 最常见的是手机的邮件程序或
已保存的 Wi-Fi 配置文件。询问用户使用哪些设备，并请他们逐一班新或移除已保存的密码。

## 多重验证（MFA）

- 可以协助用户登记新设备，但绝不代用户完成登记。
- 绝不要求用户读出多重验证码给你。
- 若用户表示收到自己并未触发的验证提示，须当作账户可能已被入侵，立即升级处理。

## 钓鱼邮件上报

若用户带着一封可疑电子邮件前来：

1. 不要点击邮件中的任何内容。
2. 询问用户有否输入过登入资料或开启过附件。
3. 若有，立即当作账户可能已被入侵并升级处理。
4. 透过官方的钓鱼邮件上报渠道举报该邮件。

## 学生助理职权范围以外

以下全部须升级处理：

- 开立、删除、重新命名或延长账户
- 变更群组成员身份或权限
- 邮箱委派或共用邮箱存取权
- 任何涉及离职职员或已毕业学生账户的事宜
- 任何怀疑账户被入侵的情况
