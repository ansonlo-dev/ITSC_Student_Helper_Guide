## 每部机器要检查什么

- 电脑能开机并进入登入画面
- 能够成功登入
- 显示器、键盘、鼠标及线材齐全并已接妥
- 教师电脑能成功输出到教室的显示设备

## 提交结果

从检查表连结页开启 **→ Computer Lab Check ←**，提交
**Computer Lab Checklist** 表格：

1. **Your name** —— 你的名字
2. **Which Computer Lab You Check?** —— 从下拉选单选出你负责的范围，例如
   “SEKG03 Teacher PC, No.01-20”

### 上报问题的格式

检查期间发现的问题，一律以此格式记录：

```
Machine Name - Issue
```

例如：

```
No.15 PC - Cannot Login
```

要写得具体 —— 机器编号加上实际发生的情况。
