# 电脑室检查

**晚间时段：星期一至五 18:30 – 20:30；星期六 09:30 – 12:30。**

每晚由四个 Computer Lab Helper 时段分工检查各电脑室。每节需要检查 **9 至 20 台
电脑**，视乎所属电脑室而定：部分时段是整间房（例如 LCH206A），部分则只是指定的
若干台机（例如 LKK 3 楼的 8 至 9 台）。你所预订时段的说明会列明。

::: warning 准时签到及签退
提早 15 分钟签退属违规行为，并非“差不多”。开班收班两头都要准时。
:::

::: tip 进不去，或者房内仍在上课
电脑室经常在公布的关门时间之前就被锁上。**致电保安请他们开门** —— 总热线
**2616 8705**、SEK **2616 8706**、LCH **2616 7250** —— 并**拍下锁上的门**，因为
保安曾表示门是开着的。若房内正在上课或考试，标记 **Room in use** 并在备注写明；
不要打断。
:::

## XClass

需要登入超过 20 部电脑的电脑室都装有 **XClass**，可以一次过检查整个电脑室。
在教师电脑上你可以：

- 集中控制所有学生电脑
- 多选或全选电脑，**一键开机或关机**
- 查看监控画面，知道哪些显示器已开启

**登入资料：**

| 栏位 | 内容 |
| --- | --- |
| Log on name | 你自己的用户名称 |
| Password | 你自己的密码 |
| Domain | `LNDAXUE` |

::: info 已安装 XClass 的房间
LBY301、LBY303、LCH201、LCH202、LCH206、LCH209、MB202、SEKG03、SEK105。
:::

这九间，就是[教室设备](/zh-CN/facilities/rooms#软件那几栏)里标了 **XClass**
的房间；那一页同时记录了 SPSS & AMOS、SDL 与各版本 Matlab 装在哪几间。

管理员可以看到每位学生在哪一台机器登入及登出 —— 但看不到在机器上做过什么。

::: tip 核对编号
要核对 XClass 上的编号与实体电脑编号是否一致 —— 曾经发现位置对不上。未安装
XClass 的房间就要逐台处理；用 `Alt`+`F4` 再按 `Enter` 是最快的关机方式。
:::

### 安全与整洁

- 离开前**把所有椅子排好**。
- 确认**桌底及桌后的插排与电线**收拾整齐、摆放安全 —— 不可杂乱缠绕、横跨通道或
  外露。

### 专用软件

如果该电脑室装有专用软件 —— **SPSS**、**AMOS**、**SDL** —— 要确认它们**真的能
启动**，而不只是桌面上有图示。哪些房间装了什么，见
[软件覆盖](/zh-CN/reference/links#软件覆盖范围)。

### 桌面玻璃隔板

设有玻璃隔板的电脑室，亦要检查**桌面玻璃隔板**。学生曾报告标签缺失或显示器无法
开启 —— 遇到这些情况要**拍照**并上传。

### 工作证明

此表格的相片上传栏位为**选填**（早上检查则是必填），但只要你上报故障就应该
上传 —— 一张相片能说清楚“not ok”到底是什么样子。

## 镜头检查方法

两种方法：

1. **Zoom** —— **设置 → 视频**，可以同时看到 C930 及 C925 两款镜头。Paul 已在
   群组发放示范影片，这里亦有附图的逐步做法：[用 Zoom 测试镜头](/zh-CN/tips/troubleshooting#用-zoom-测试镜头)。
2. **系统内置的 Windows Camera App。**

::: warning LKKG0X —— 只能用 Zoom
LKKG0X 无法在系统 Camera App 更改镜头设置，这些房间必须用 Zoom 检查。
:::

最常见的误报，是有人把**镜头盖**关上或把镜头拨开，令画面全黑。上报之前先检查
镜头盖。

## 常见故障

- 投影模式未设为 **Duplicate／Extend**
- 电源插头被拔出
- 显示器线松脱
- 触控面板音量被静音或调到最低
- 镜头盖没有打开

以上每一项，在机旁一分钟之内都修得好；而电脑室里大部分「PC cannot power on」和
「没有声音」的上报，最后都是头两项，加上 Windows 选错了输出设备。写任何东西之前，
先走一次[你可以当场解决的故障](/zh-CN/tips/troubleshooting#你可以当场解决的故障)
—— 然后把仍然存在的问题，用 `Machine Name - Issue` 的格式连同照片上报。

## 离开之前

::: tip 收尾流程
1. **关闭所有你检查过的电脑** —— 有 XClass 就用 XClass，否则逐台按 `Alt`+`F4`、
   `Enter`。
2. **关闭投影仪及实物投影仪。**
3. **关掉控制面板。**
4. **留一盏灯开着。**
:::
