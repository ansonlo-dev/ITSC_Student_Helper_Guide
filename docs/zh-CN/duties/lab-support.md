## XClass

需要登入超过 20 部电脑的电脑室都装有 **XClass**，可以一次过检查整个电脑室。
在教师电脑上你可以：

- 集中控制所有学生电脑
- 多选或全选电脑，**一键开机或关机**
- 查看监控画面，知道哪些显示器已开启

**登入资料：**

| 栏位 | 内容 |
| --- | --- |
| Log on name | 你自己的用户名称 |
| Password | 你自己的密码 |
| Domain | `LNDAXUE` |

::: info 已安装 XClass 的房间
LBY301、LBY303、LCH201、LCH202、LCH206、LCH209、MB202、SEKG03、SEK105。
:::

管理员可以看到每位学生在哪一台机器登入及登出 —— 但看不到在机器上做过什么。

::: tip 核对编号
要核对 XClass 上的编号与实体电脑编号是否一致 —— 曾经发现位置对不上。未安装
XClass 的房间就要逐台处理；用 `Alt`+`F4` 再按 `Enter` 是最快的关机方式。
:::

**Computer Lab Checklist**，从 **→ Computer Lab Check ←** 开启。

检查表有两个版本 —— **有**桌面玻璃隔板的电脑室，以及**没有**的 —— 因为有隔板
的房间多几个项目。以下是“没有隔板”的版本。

### 第 1 页

| # | 题目 | 备注 |
| --- | --- | --- |
| 1 | **Your name** | 你的名字 |
| 2 | **Which Computer Lab You Check?** | 下拉选单，例如“SEKG03 No.21-45” |

::: tip 上报格式
表格顶部已列明，问题一律以此格式上报：

```
Machine Name - Issue
```

例如 `No.15 PC - Cannot Login`。
:::

### 桌面玻璃隔板

设有玻璃隔板的电脑室，亦要检查**桌面玻璃隔板**。学生曾报告标签缺失或显示器无法
开启 —— 遇到这些情况要**拍照**并上传。

### 工作证明

此表格的相片上传栏位为**选填**（早上检查则是必填），但只要你上报故障就应该
上传 —— 一张相片能说清楚“not ok”到底是什么样子。

## 镜头检查方法

两种方法：

1. **Zoom** —— 登入后 **设置 → 视频**，可以同时看到 C930 及 C925 两款镜头。
   Paul 已在群组发放示范影片。
2. **系统内置的 Windows Camera App。**

::: warning LKKG0X —— 只能用 Zoom
LKKG0X 无法在系统 Camera App 更改镜头设置，这两间房必须用 Zoom 检查。
:::

最常见的误报，是有人把**镜头盖**关上或把镜头拨开，令画面全黑。上报之前先检查
镜头盖。

## 常见故障

- 投影模式未设为 **Duplicate／Extend**
- 电源插头被拔出
- 显示器线松脱
- 触控面板音量被静音或调到最低
- 镜头盖没有打开

## 离开之前

::: tip 收尾流程
1. **关闭所有你检查过的电脑** —— 有 XClass 就用 XClass，否则逐台按 `Alt`+`F4`、
   `Enter`。
2. **关闭投影仪及实物投影仪。**
3. **关掉控制面板。**
4. **留一盏灯开着。**
:::
