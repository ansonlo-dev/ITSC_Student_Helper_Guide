# 电脑室支援

## 例行巡查

开班时巡视电脑室一次，其后定时再巡。

::: tip 巡查检查清单
- 每部工作站都能开机并进入登入画面
- 显示器、键盘、鼠标及各种线材齐全并已接妥
- 没有工作站在登入状态下无人看管
- 椅子推回原位，桌面没有垃圾
- 打印机有纸；没有错误灯亮起
- 空调及照明运行正常
- 故障机器已贴上“暂停服务”标示并已上报
:::

## 常见工作站故障

| 症状 | 首先检查 |
| --- | --- |
| 没有电源 | 墙上开关、电源线两端、插线板 |
| 没有画面 | 显示器电源、视频线是否插实、换另一个接口 |
| 死机 | 先等一会，再强制重启；记下是哪个程序导致 |
| 无法登入 | Caps Lock、用户名格式、网线、看看其他机器是否同样情况 |
| 没有网络 | 网线是否插实、指示灯、测试同一交换机上的另一台机 |
| 机器很慢 | 检查是否有卡住的更新或失控进程；重启 |
| 软件不见了或无法开启 | 确认该软件本应在这个系统镜像中；若不是则上报 |

::: warning 一台机还是全部机？
必须先确认故障只影响一台工作站，还是整个电脑室。全室性的故障属于网络或服务器
问题 —— 应立即升级处理，而不是逐台电脑去排查。
:::

## 上报故障机器

1. 清楚贴上标示，让用户避开。
2. 记下机器的资产编号或主机名、房间号，以及症状。
3. 注明你已经试过什么方法。
4. 在故障系统中登记；若电脑室繁忙或即将有课堂使用，同时通知职员。

## 在电脑室协助用户

- 未经同意，不要碰用户的键盘或鼠标。
- 尽可能引导用户自己操作 —— 可以省下他下次再来的时间。
- 提醒用户在任何重启前先保存工作。
- 提醒用户电脑室的工作站可能会在重启后重置：文件必须保存到个人或云端保存空间，
  切勿存放在本机桌面。

## 课堂预约期间

- 查看你当班时段的预约时间表。
- 在预约课堂开始前先到电脑室，确认教学电脑及投影仪运行正常。
- 课堂进行期间不要大声排查故障；请等待适当时机，或与用户移步室外处理。
