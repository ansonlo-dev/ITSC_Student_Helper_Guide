# 职务总览

学生助理的职务主要分为几个经常出现的范畴。第一次被编排到某项职务前，请先阅读
以下对应的页面 —— 每一页都是可直接使用的检查清单。

| 职务 | 涵盖范围 |
| --- | --- |
| [服务柜台](/zh-CN/duties/service-counter) | 招呼用户、记录工单、前线分流 |
| [电脑室支援](/zh-CN/duties/lab-support) | 电脑室巡查、工作站故障、软件问题 |
| [影音及教室设备](/zh-CN/duties/av-equipment) | 投影仪、麦克风、课堂录影、器材外借 |
| [账户与密码](/zh-CN/duties/accounts) | 重置密码、启用账户、多重验证 —— 以及其界限 |
| [打印服务](/zh-CN/duties/printing) | 打印队列、配额、卡纸、耗材 |

## 每宗工单的共通流程

无论是哪一项职务，流程都是一样的：

1. **招呼** 用户，弄清楚他们真正需要什么。
2. **核实** 身份 —— 若工单涉及账户或个人资料。
3. **诊断** —— 使用[故障排查手册](/zh-CN/tips/troubleshooting)。
4. **解决** —— 若在你的职权范围内。
5. **升级** —— 若超出职权范围，详见[联系与升级处理](/zh-CN/reference/contacts)。
6. **记录** 处理经过，让下一位同事掌握来龙去脉。

## 认清自己的界限

::: danger 一律升级，切勿自行摸索
若工单涉及账户权限、安全、资料遗失，或任何你未受过训练的事项，请交由全职职员
处理。乱猜所花的时间，远比开口问要多得多。
:::
