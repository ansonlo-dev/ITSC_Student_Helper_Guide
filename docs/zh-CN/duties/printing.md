# 打印服务

打印是所有服务中现场查询最多的一项，而当中大部分都是那几个相同的问题。

## 常见成因

| 用户说 | 通常原因 |
| --- | --- |
| “什么都没印出来” | 送去了错的打印机，或未在机器上释放打印工作 |
| “它说我没有配额” | 配额用完，或未充值 |
| “印出来是白纸” | 碳粉用完，或文件本身确实是空白 |
| “一直印不完” | 文件太大，或队列卡住 |
| “印出来有条纹／很浅色” | 碳粉不足，或需要摇匀 |
| “我的笔记本电脑印不到” | 缺少驱动程序，或未连接校园网络 |

## 标准处理顺序

1. 确认打印工作 **送到了哪一台打印机**。
2. 检查打印队列 —— 工作是卡住、被暂停，还是其实已经印了？
3. 查看打印机本身的显示屏有没有错误（缺纸、碳粉、卡纸、离线）。
4. 检查用户的配额或余额。
5. 请用户重新送出 **一页测试页**，而不是整份文件再印一次。

::: warning 重复的打印工作
用户见到没有反应时，往往会连按几次打印。释放之前先清除多余的工作，否则用户会拿到
五份副本，而且五份都会扣配额。
:::

## 清除卡纸

1. 阅读打印机显示屏 —— 它会指出是哪道门、哪个纸盘。
2. 打开指示的门，用双手 **顺着出纸方向** 慢慢把纸拉出。
3. 不要撕破纸张；务必清走每一片碎纸，否则会再次卡纸。
4. 不要触碰定影器 —— 它非常烫。
5. 关好所有门，让打印机重置，然后印一张测试页。
6. 若在同一位置再次卡纸，将该机暂停服务并上报。

## 耗材

- 在纸盘用完之前就补纸，装入前先把纸叠抖散。
- 不要装纸超过纸盘的上限线。
- 碳粉：轻轻摇匀可以撑一段时间，但仍应更换，不要放着让它一直印出浅色文件。
- 及早上报耗材不足 —— 不要等到断供才处理。

## 配额与付款

冷静地解释配额制度；用户经常误以为那是故障。告诉他们在哪里查看余额、如何充值。
切勿自行调整配额 —— 应升级处理。

## 扫描与复印

- 扫描前先确认扫描件要送去哪里（电子邮件或网络文件夹）。
- 提醒用户从玻璃面板或送稿器取回原稿。
- 遗留在机器上的机密文件应交到服务柜台，不要阅读，也不要丢弃。
